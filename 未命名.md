### 常见框架对比


### 按用途选择

| 需求            | 推荐框架                                    |
| ------------- | --------------------------------------- |
| 写简单 Web 接口    | Flask                                   |
| 写机器人 REST API | Flask / FastAPI                         |
| 写机器人状态监控后端    | Flask + Socket.IO / FastAPI + WebSocket |
| 写大型后台管理系统     | Django                                  |
| 写高并发实时通信      | Tornado / aiohttp                       |
| 写 AI 模型演示界面   | Gradio / Streamlit                      |
| 写数据可视化看板      | Dash / Streamlit                        |
| 写小工具网页        | Bottle / Flask                          |

### 对机器人项目的建议

| 项目类型       | 推荐方案                  | 原因                      |
| ---------- | --------------------- | ----------------------- |
| ROS2 机器人后端 | Flask + Socket.IO     | 稳定、简单、适合 REST API 和实时推送 |
| 新项目 API 服务 | FastAPI               | 类型清晰、接口文档自动生成、性能较好      |
| 实时状态推送     | WebSocket / Socket.IO | 适合机器人位置、任务状态、传感器状态推送    |
| AI 识别演示    | Gradio                | 快速展示 YOLO、目标检测、图像识别结果   |
| 数据分析页面     | Streamlit             | 快速展示实验数据、图表和模型结果        |

### 简单结论

| 场景              | 最推荐                           |
| --------------- | ----------------------------- |
| 入门学习 Python Web | Flask                         |
| 做大型网站           | Django                        |
| 做现代 API         | FastAPI                       |
| 做机器人 Web 服务     | Flask / FastAPI               |
| 做实时通信           | Tornado / aiohttp / Socket.IO |
| 做 AI Demo       | Gradio / Streamlit            |
| 做数据看板           | Dash / Streamlit              |
