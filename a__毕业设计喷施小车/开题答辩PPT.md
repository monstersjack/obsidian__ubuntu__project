### 题目

基于蓝莓种植区作业地图的蓝莓精准喷施机器人路径规划与导航控制研究

### 研究背景

- 蓝莓大棚行间空间狭窄，植株排列具有规律性，但地面、棚架和临时器具会形成局部障碍。
- 人工喷施存在作业效率低、路线重复性差、喷施位置难以复现等问题。
- CAD 图纸可以表达作业行、转弯段、禁入区和喷施位置，但需要转换为机器人能够执行的路径与动作。
- 本研究以导航精度和喷施位置控制为重点，喷施机构作为路径执行任务的一部分进行验证。

### 总体目标

设计一套面向蓝莓大棚的 CAD 路线喷施机器人系统，实现：

1. 解析 CAD 作业图并生成带坐标的目标路径。
2. 使用全站仪、IMU 和轮速信息获得车体位姿。
3. 对直线、曲线和转角作业路径进行稳定跟踪。
4. 在非喷施转场区域进行全局路径规划和局部避障。
5. 在到达指定作业区时，按照位置和运动状态控制喷施装置。

### 系统总体流程

```text
CAD图纸
  -> 路径解析与坐标转换
  -> 目标路径和作业点
  -> 全站仪、IMU、轮速多源定位
  -> /robot_pose
  -> RPP直线和曲线跟踪
  -> /task_cmd_vel
  -> cmd_vel_mux
  -> /cmd_vel
  -> 轮驱和喷施状态机
```

### 参考论文借鉴内容

参考论文为《温室超声波驱虫机器人导航系统设计与试验》，其导航系统包括：

| 模块 | 参考论文方法 | 本课题对应方法 |
|---|---|---|
| 地图构建 | 三维激光雷达与点云滤波 | 可根据实际设备选择激光地图或现有场地地图 |
| 定位 | 自适应蒙特卡罗定位 AMCL | 全站仪棱镜位置、IMU 航向和轮速融合 |
| 全局规划 | 改进 Dijkstra | 非喷施转场路线规划，CAD 喷施线保持原路径 |
| 局部规划 | TEB | 转场区域局部避障；喷施行遇障碍优先停车停喷 |
| 作业执行 | 超声波驱虫 | 立杆式喷施装置和作业点触发 |
| 评价指标 | 地图误差、路径长度、折点数量、导航误差 | 定位误差、路径跟踪误差、喷施触发误差 |

### 多源定位方案

本课题不直接照搬 AMCL，而是根据已有硬件建立多源定位方案：

| 数据源 | 主要作用 |
|---|---|
| 全站仪棱镜坐标 | 提供地图坐标系下的绝对位置 |
| IMU | 提供高频角速度、姿态和航向变化 |
| 轮速里程计 | 提供短时位移、速度和差速转弯约束 |
| 激光雷达 | 主要用于障碍检测，具备条件时可用于辅助定位 |

建议先实现“全站仪位置 + IMU 航向 + 轮速约束”的稳定版本，再扩展误差状态扩展卡尔曼滤波器。全站仪短时失锁时，由 IMU 和轮速维持短时间预测；全站仪恢复后，再校正累计误差。

### 路径规划方案

路径分为两类：

| 路径类型 | 使用方法 | 原因 |
|---|---|---|
| CAD 喷施行 | RPP 路径跟踪 | 必须严格跟随作业线，不能随意改变喷施位置 |
| 非喷施转场 | Dijkstra 或改进 Dijkstra | 在地图上寻找通道级路线 |
| 转场局部避障 | TEB 或停车策略 | 根据障碍和底盘运动约束调整短时轨迹 |

喷施行检测到障碍物时，优先停止车辆并关闭喷施输出，避免为了绕障而偏离 CAD 作业线。

### 研究内容

1. **CAD 作业路线解析**：提取直线、曲线、转弯区、禁入区和喷施作业点，统一 CAD、地图和车体坐标系。
2. **多源定位与校准**：完成全站仪棱镜到车体的外参标定、IMU 初始航向标定、轮速参数标定和时间同步。
3. **路径规划与跟踪**：使用 Dijkstra 处理转场路线，使用 RPP 跟踪 CAD 直线和曲线，研究横向误差与航向误差的控制方法。
4. **局部避障与安全控制**：在转场区域评估 TEB 或其他局部规划方法，在喷施行建立停喷停车逻辑。
5. **喷施任务状态机**：按照到达作业点、运行状态、定位有效性和障碍状态控制喷施装置。
6. **实验评价**：比较不同定位组合、不同速度和不同路径类型下的定位误差、跟踪误差和作业触发误差。

### 拟解决的关键问题

| 问题 | 解决思路 |
|---|---|
| 全站仪坐标与 CAD 坐标不一致 | 建立原点、轴向、单位和旋转角度的统一转换 |
| IMU 航向漂移 | 初始航向标定，并用轮速和全站仪运动轨迹辅助校正 |
| 轮速打滑导致直线走歪 | 标定轮径和轮距，加入轮速约束和横向误差反馈 |
| 全站仪偶尔失锁 | 判断数据新鲜度、连续性和残差，短时切换到预测模式 |
| 路径转角过急 | 对转场路径进行平滑，对 CAD 转角采用受控减速和定角转弯 |
| 喷施位置与车体位置不同 | 使用喷头相对车体的固定外参计算实际喷施点 |

### 实验设计

#### 多源定位对比

| 实验组 | 定位输入 | 目的 |
|---|---|---|
| A | 纯轮速 | 测量累计漂移 |
| B | IMU + 轮速 | 验证短时姿态和运动估计 |
| C | 全站仪 + IMU | 验证绝对位置和航向组合效果 |
| D | 全站仪 + IMU + 轮速 | 验证完整多源定位效果 |
| E | 全站仪短时失锁 | 验证系统容错和恢复能力 |

#### 路径跟踪测试

- 直线：测试横向误差、终点误差和航向误差。
- 长方形：测试 90 度转角、边长误差和闭合误差。
- 圆形：测试半径误差、圆周跟踪误差和角速度稳定性。
- CAD 复杂路线：测试路径完成率、平均误差和最大误差。

#### 主要评价指标

| 指标 | 含义 |
|---|---|
| 横向误差 | 机器人偏离目标作业线的距离 |
| 纵向误差 | 机器人沿目标路线方向的位置误差 |
| 航向误差 | 车体方向与目标路线方向的夹角 |
| 位置 RMSE | 多次采样的综合定位精度 |
| 路径长度 | 规划路径或实际路径的长度 |
| 大角度折点数 | 路径急转弯程度 |
| 喷施触发误差 | 实际喷施位置与 CAD 指定位置的距离 |
| 失锁恢复时间 | 全站仪恢复后重新得到有效位姿的时间 |

### 预期成果

1. 一套 CAD 作业图到机器人执行路径的转换流程。
2. 一套适用于大棚场景的全站仪、IMU 和轮速多源定位方法。
3. 一套面向直线、曲线和转角的路径跟踪控制方法。
4. 一套喷施启动、暂停、故障和结束的任务状态机。
5. 一组定位精度、路径跟踪精度和喷施触发精度实验数据。

### 论文边界说明

- 参考论文中的 AMCL、Cartographer 3D 和 TEB 是其具体实现，不应直接写成当前项目已经完成的功能。
- 本课题优先研究 CAD 喷施路径、多源定位和路径跟踪控制。
- 激光雷达首先承担障碍检测任务；只有完成可靠的激光匹配验证后，才将其作为定位来源。
- 农药种类、喷量控制和冠层变量施药可以作为后续扩展，不作为当前开题阶段必须完成的核心算法。
