### 一、参考论文讲了什么

参考论文题目为《温室超声波驱虫机器人导航系统设计与试验》。论文的目标是让机器人在温室行间自主行走，并在指定位置进行超声波驱虫。其研究流程可以概括为：

```text
温室环境建图
    -> 机器人定位
    -> 全局路径规划
    -> 局部轨迹优化
    -> 底盘控制
    -> 驱虫效果验证
```

论文把导航问题拆成三个核心问题：

| 问题 | 论文采用的方法 | 简单理解 |
|---|---|---|
| 机器人在哪里 | 自适应蒙特卡罗定位 AMCL | 用轮速预测，再用激光和地图纠正 |
| 从哪里走到哪里 | 改进 Dijkstra | 在地图上寻找一条安全路线，并减少多余折点 |
| 当前几秒怎么走 | TEB | 根据障碍、速度和底盘约束优化局部轨迹 |

### 二、论文的硬件和软件结构

论文使用阿克曼底盘、三维激光雷达、IMU、轮速编码器和上位机控制器。软件上分为任务管理层、导航算法层、运动控制层和驱虫执行层。

```text
任务管理层
    -> 选择作业行和目标点
导航算法层
    -> 地图、定位、全局规划、局部规划
运动控制层
    -> 将轨迹转换为底盘速度
驱虫执行层
    -> 在指定位置开启超声波装置
```

你的项目可以保留这个分层思想，但将执行层替换为立杆式喷施，并把目标路径从地图目标点改为 CAD 作业路线。

### 三、自适应蒙特卡罗定位 AMCL

#### 3.1 AMCL 要解决的问题

轮速里程计只能估计机器人走了多远，长时间运行后会产生累计误差。激光雷达可以观察周围的棚架、墙体和障碍物，并与已有地图进行匹配。因此 AMCL 的基本思路是：

```text
轮速预测下一时刻可能的位置
    -> 激光雷达与地图匹配
    -> 判断哪些位置更可信
    -> 保留高概率位置
```

#### 3.2 粒子表示位姿

AMCL 不只保存一个位姿，而是保存很多个候选位姿，每个候选位姿称为一个粒子：

| 粒子 | X | Y | 航向 | 权重 |
|---|---:|---:|---:|---:|
| 1 | 1.98 | 2.01 | 90 度 | 0.70 |
| 2 | 2.04 | 1.97 | 91 度 | 0.20 |
| 3 | 2.15 | 2.08 | 87 度 | 0.02 |

权重表示该粒子与真实位置的接近程度。经过多次更新后，高权重区域会留下更多粒子，粒子群的中心就作为当前机器人位姿。

#### 3.3 概率表达式

论文给出：

```text
bel(x_t) = p(x_t | z_1:t, u_1:t)
```

含义是：已知过去的激光观测 `z_1:t` 和过去的运动输入 `u_1:t`，机器人在时刻 `t` 位于位姿 `x_t` 的概率。

| 符号 | 含义 |
|---|---|
| `x_t` | 当前机器人位姿，包括 X、Y 和航向 |
| `u_t` | 当前轮速或运动输入 |
| `z_t` | 当前激光雷达观测 |
| `bel(x_t)` | 当前位姿的概率分布 |

#### 3.4 AMCL 四个步骤

##### 第一步：运动预测

由轮速计算机器人前进距离和转角：

```text
Δs = (Δs_left + Δs_right) / 2
Δyaw = (Δs_right - Δs_left) / wheel_base
```

再根据上一时刻位姿预测：

```text
x_t = x_(t-1) + Δs * cos(yaw)
y_t = y_(t-1) + Δs * sin(yaw)
yaw_t = yaw_(t-1) + Δyaw
```

实际系统会加入随机噪声，因为轮速并不完全准确。

##### 第二步：激光观测更新

对每个粒子假设一次机器人位置，计算这个位置下的激光扫描是否应该与地图匹配：

```text
地图预测的激光轮廓 ≈ 实际雷达扫描轮廓
```

匹配程度越高，粒子权重越大。

##### 第三步：权重归一化

```text
w_i = w_i / sum(w_i)
```

所有粒子的权重被归一化，使权重总和为 1。

##### 第四步：重采样

高权重粒子被复制，低权重粒子被删除。机器人位置越明确，粒子越集中；机器人位置越不确定，粒子分布越分散。

#### 3.5 “自适应”的含义

自适应 AMCL 会根据定位不确定程度调整粒子数量：

| 情况 | 粒子数量策略 |
|---|---|
| 位置非常明确 | 减少粒子，降低计算量 |
| 温室行间重复、匹配不明确 | 增加粒子，扩大搜索范围 |
| 初始位置未知 | 使用较多粒子进行全局定位 |

#### 3.6 AMCL 的优点和局限

| 优点 | 局限 |
|---|---|
| 不需要直接测量绝对坐标 | 必须有较可靠的栅格地图 |
| 能处理一定程度的轮速漂移 | 温室重复行结构可能产生相似匹配 |
| 能处理位姿不确定性 | 棚架、叶片和人员遮挡会影响激光匹配 |
| 是成熟的 ROS 导航方法 | 不是厘米级测量系统 |

#### 3.7 与你的全站仪定位的区别

论文使用激光和地图估计绝对位姿，而你的全站仪直接给出棱镜的绝对坐标。你的方案可以写成：

```text
全站仪：绝对位置
IMU：高频航向变化
轮速：短时位移和速度约束
激光雷达：障碍检测，必要时辅助定位
```

不建议让 AMCL 和全站仪同时无约束地发布两个不同的 `/robot_pose`。如果后续加入 AMCL，应明确一个主定位源，另一个作为备用或一致性检查。

### 四、改进 Dijkstra 全局规划

#### 4.1 Dijkstra 的基本作用

Dijkstra 在栅格地图中寻找起点到终点的最低代价路线。每个栅格都有代价：

| 地图区域 | 代价 |
|---|---|
| 可自由行驶区域 | 低 |
| 靠近障碍物区域 | 高 |
| 障碍物内部 | 不可通行 |

算法从起点逐步扩展代价最小的节点，直到到达目标点，然后从目标点反向回溯得到路径。

#### 4.2 普通 Dijkstra 的问题

普通栅格路径经常出现：

- 路径点太密或太多；
- 路线呈锯齿状；
- 折点数量多；
- 靠近障碍物；
- 转弯过急，不适合实际底盘。

#### 4.3 论文中的四项改进

##### 改进一：障碍物膨胀和安全代价

论文给地图增加膨胀层，设置膨胀半径为 `0.2 m`。机器人即使没有进入障碍物本体，靠得太近也会获得较高代价。

这样规划结果会主动远离障碍物。

##### 改进二：附近节点二次检查

论文对候选节点周围的 8 个邻近方向进行再次检查。如果附近代价超过阈值 `L`，就删除这个节点。

```text
附近代价 >= L：节点不安全，删除
附近代价 < L：节点保留
```

这一步考虑了机器人自身尺寸，而不是只判断一个地图栅格是否为空闲。

##### 改进三：路径插值

如果相邻路径点距离太大，就插入中间点：

```text
P0 ---------------- P1
```

变成：

```text
P0 -------- P0.5 -------- P1
```

插值公式为：

```text
x_p = x_0 + λ(x_1 - x_0)
y_p = y_0 + λ(y_1 - y_0)
```

其中 `0 <= λ <= 1`。插值后，局部规划器和路径跟踪控制器可以获得更连续的目标点。

##### 改进四：角度平滑和直线化

先计算相邻路径段的方向角：

```text
θ1 = atan2(y1-y0, x1-x0)
θ2 = atan2(y2-y1, x2-x1)
```

若角度差超过阈值，就在折点附近增加平滑点。

论文还借鉴 JPS 的直线化思想，对三个连续点进行检查：

```text
P0 -> P1 -> P2
```

如果 `P0` 到 `P2` 的直线段不碰撞，并且安全代价满足阈值，就删除中间点 `P1`：

```text
P0 -------------- P2
```

这里的关键不是单纯缩短距离，而是必须同时满足：

1. 直线段没有穿过障碍物。
2. 直线段经过的栅格都满足安全代价。
3. 机器人膨胀尺寸通过检查。

#### 4.4 路径评价指标

##### 路径长度

```text
L = sum(distance(P_i, P_(i+1)))
```

长度越短，通常说明路线更接近最优。

##### 大角度折点数量

论文统计转角超过 `60 度` 的折点数量，用来表示路线是否急转弯过多。

##### 重复实验标准差

论文对每种方法重复实验，统计平均值、最小值、最大值和标准差。标准差越小，说明规划结果越稳定。

#### 4.5 论文的规划结果

直线行间环境：

| 方法 | 平均路径长度 | 大于 60 度折点数 |
|---|---:|---:|
| A* + TEB | 2.032 m | 1.4 |
| Dijkstra + TEB | 2.084 m | 1.6 |
| 改进 Dijkstra + TEB | 2.019 m | 0.4 |

弯曲行间环境：

| 方法 | 平均路径长度 | 大于 60 度折点数 |
|---|---:|---:|
| A* + TEB | 2.681 m | 3.0 |
| Dijkstra + TEB | 2.830 m | 3.8 |
| 改进 Dijkstra + TEB | 2.670 m | 2.4 |

论文说明，改进后的 Dijkstra 在测试场景中具有更短的路径、更少的急转弯和更好的重复性。但这些数字只代表论文测试环境，不能直接当作你的机器人实验结果。

### 五、TEB 局部规划

#### 5.1 TEB 的作用

TEB 的全称是 `Timed Elastic Band`，即“时间弹性带”。它不是从整个地图上重新寻找完整路线，而是在全局路线附近生成短时间局部轨迹。

TEB 解决的问题是：

> 机器人未来几秒怎样走，才能避开障碍，同时符合速度、加速度和底盘转向限制？

#### 5.2 TEB 的轨迹表示

TEB 用一串带时间间隔的位姿表示局部轨迹：

```text
(x0, y0, θ0, Δt0)
(x1, y1, θ1, Δt1)
(x2, y2, θ2, Δt2)
```

其中：

- `x、y` 是机器人位置；
- `θ` 是机器人航向；
- `Δt` 是相邻位姿之间的运动时间。

#### 5.3 为什么叫“弹性带”

可以把局部轨迹想成一条有弹性的带子：

```text
起点 o-----o-----o-----o 终点
```

当障碍物出现在路径附近时，轨迹被推向安全区域：

```text
起点 o----╭------╮----o 终点
           障碍物
```

当相邻点距离过大、转弯过急或速度不合理时，TEB 会重新调整路径点和时间间隔。

#### 5.4 TEB 的优化内容

| 代价或约束 | 作用 |
|---|---|
| 障碍物距离 | 避免碰撞 |
| 全局路径距离 | 尽量不偏离全局路线 |
| 时间代价 | 提高行驶效率 |
| 最大线速度 | 防止速度超限 |
| 最大角速度 | 防止旋转过快 |
| 加速度限制 | 避免突然加速和减速 |
| 最小转弯半径 | 满足底盘运动学 |
| 轨迹平滑度 | 减少方向突变 |

TEB 不是只寻找“最短路径”，而是在安全、速度、路径跟随和底盘可执行性之间进行综合优化。

#### 5.5 阿克曼底盘的运动学约束

论文使用阿克曼底盘，不能原地旋转，需要满足最小转弯半径：

```text
R = v / ω
```

其中：

- `R` 是当前转弯半径；
- `v` 是线速度；
- `ω` 是角速度。

如果底盘允许的最小转弯半径为 `R_min`，就必须满足：

```text
abs(v / ω) >= R_min
```

如果规划出的速度要求转弯半径小于底盘允许值，TEB 应当调整速度或改变轨迹。

#### 5.6 TEB 与 DWA 的区别

| 项目 | DWA | TEB |
|---|---|---|
| 基本思路 | 采样速度并预测轨迹 | 优化带时间的轨迹点 |
| 时间信息 | 相对简单 | 明确优化时间间隔 |
| 底盘约束 | 需要额外处理 | 可以直接加入优化约束 |
| 阿克曼适应性 | 需要专门改造 | 更容易加入最小转弯半径 |
| 轨迹平滑 | 依赖速度采样 | 可直接优化轨迹连续性 |
| 计算复杂度 | 通常较低 | 通常较高 |

论文选择 TEB，是因为其机器人为阿克曼结构，需要考虑最小转弯半径和非完整运动约束。

### 六、这三种方法如何对应你的项目

你的项目是 CAD 喷施机器人，不应把三种方法全部用于同一段路径。

```text
全站仪 + IMU + 轮速
        -> 多源定位
        -> /robot_pose

非喷施转场
        -> Dijkstra全局路线
        -> TEB局部避障

CAD喷施行
        -> RPP严格跟踪
        -> 喷施状态机控制喷头
```

| 场景 | 推荐方法 | 原因 |
|---|---|---|
| 全站仪正常工作 | 全站仪 + IMU + 轮速融合 | 位置精度和实时性互补 |
| 全站仪短时失锁 | IMU + 轮速预测 | 保持短时间连续运动估计 |
| 非喷施转场 | Dijkstra + TEB | 可以绕开临时障碍 |
| CAD 喷施直线 | 直线误差控制或 RPP | 保持喷施线位置 |
| CAD 喷施曲线 | RPP | 按前瞻点跟踪目标曲线 |
| 喷施行遇到障碍 | 停车并停喷 | 不允许绕障导致施药位置偏移 |

### 八、建议你的论文怎样写

建议论文中使用下面的技术路线：

> 本研究借鉴温室农业机器人导航系统的分层设计思想，将系统划分为多源定位、路径规划、路径跟踪和作业执行四个模块。针对全站仪能够提供高精度绝对位置、IMU 能够提供高频航向信息以及轮速计能够提供短时运动约束的特点，构建面向 CAD 作业路径的多源定位方法。在非喷施转场区域采用全局路径规划和局部避障，在 CAD 喷施行内采用 RPP 控制器严格跟踪目标路径，并根据定位有效性、障碍状态和作业位置控制喷施装置。

- 平滑前与平滑后路径；
- 不同障碍膨胀半径；

#### 9.3 导航精度实验

至少记录：

| 指标 | 含义 |
|---|---|
| 横向误差 | 偏离 CAD 目标线的距离 |
| 纵向误差 | 沿目标线方向的位置误差 |
| 航向误差 | 车体航向与目标路径方向的差值 |
| 位置 RMSE | 连续采样点的综合误差 |
| 最大误差 | 最差情况下的偏差 |
| 标准差 | 重复实验稳定性 |
| 喷施触发误差 | 实际喷施位置与目标作业点的距离 |

### 十、最终理解

可以用一句话记住三种方法：

```text
AMCL：判断机器人在哪里。
Dijkstra：决定机器人整体走哪条路线。
TEB：决定机器人当前几秒怎样安全地走。
```

对于你的项目，还需要补充：

```text
全站仪、IMU、轮速：得到更可靠的机器人位姿。
RPP：严格跟踪 CAD 喷施线。
喷施状态机：决定什么时候开启、暂停和关闭喷施。
```

你的论文重点不应是简单堆叠 AMCL、Dijkstra 和 TEB，而应说明：

> 为什么蓝莓大棚需要高精度绝对定位，为什么 CAD 喷施行不能被普通局部避障路径替换，以及多源定位误差如何影响最终喷施位置。
