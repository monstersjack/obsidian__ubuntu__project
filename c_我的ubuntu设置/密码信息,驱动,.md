### YT6801 网卡驱动 DKMS 永久安装指南

#### 背景

yt6801 是 Motorcomm 网卡驱动，直接用 `insmod` 加载的话重启就会丢失。本指南通过 DKMS 实现永久安装，内核升级时自动重编译。

#### 前提条件

- 驱动源码目录：`/home/jack/b_attachment/网卡驱动/yt6801-driver`
- 驱动版本：`1.0.31`
- 工具：dkms、build-essential、linux-headers

---

#### 一、Makefile 修复（Linux 6.8+ 内核需要）

新版内核启用了 `CONFIG_MITIGATION_RETPOLINE`，objtool 会将函数指针间接调用当作致命错误。需要在 Makefile 的 `yt6801-objs` 行之后添加以下内容（约第 63 行）：

```makefile
OBJECT_FILES_NON_STANDARD_fuxi-gmac-net.o := y
OBJECT_FILES_NON_STANDARD_fuxi-gmac-ethtool.o := y
OBJECT_FILES_NON_STANDARD_fuxi-gmac-hw.o := y
OBJECT_FILES_NON_STANDARD_fuxi-gmac-pci.o := y
OBJECT_FILES_NON_STANDARD_fuxi-gmac-common.o := y
OBJECT_FILES_NON_STANDARD_fuxi-gmac-ioctl.o := y
OBJECT_FILES_NON_STANDARD_fuxi-gmac-phy.o := y
OBJECT_FILES_NON_STANDARD_fuxi-gmac-desc.o := y
OBJECT_FILES_NON_STANDARD_fuxi-efuse.o := y
```

---

#### 二、安装步骤

```bash
# 进入源码目录
cd /home/jack/b_attachment/网卡驱动/yt6801-driver

# 1. 安装编译工具链
sudo apt install -y dkms build-essential linux-headers-$(uname -r)

# 2. 清理旧的编译产物
make clean

# 3. 复制源码到 DKMS 标准位置
sudo mkdir -p /usr/src/yt6801-1.0.31
sudo cp -r ./* /usr/src/yt6801-1.0.31/

# 4. 移除旧注册（如果有）
sudo dkms remove yt6801/1.0.31 --all 2>/dev/null

# 5. 注册到 DKMS
sudo dkms add -m yt6801 -v 1.0.31

# 6. 编译驱动
sudo dkms build -m yt6801 -v 1.0.31

# 7. 安装到内核模块目录
sudo dkms install -m yt6801 -v 1.0.31

# 8. 立即加载驱动（不用重启）
sudo modprobe yt6801
```

#### 六、原理说明

| 步骤 | 作用 |
|------|------|
| apt install dkms | DKMS（Dynamic Kernel Module Support）框架 |
| make clean | 清除上次编译残留 |
| cp 到 /usr/src/ | DKMS 标准源码存放路径 |
| dkms add | 向 DKMS 注册模块 |
| dkms build | 针对当前内核编译 .ko 文件 |
| dkms install | 将 .ko 安装到 `/lib/modules/$(uname -r)/updates/dkms/` |
| modprobe | 立即加载，无需重启 |
| OBJECT_FILES_NON_STANDARD | 跳过 objtool retpoline 检查（仅 Linux 6.8+ 需要） |

以后 `apt upgrade` 升级内核时，DKMS 会自动为新内核重编译 yt6801，就像 NVIDIA 驱动一样。

### 1. `lsmod | grep yt6801`
- `lsmod` 列出 **当前已加载的内核模块**（可以理解为“已启用的驱动”）。
- `| grep yt6801` 只把包含 `yt6801` 的那一行过滤出来。
**目的**：确认 YT6801 驱动真的被装进内核了。
**正常输出**类似：

```
yt6801     163840  0
```

如果啥都没有 → 驱动没加载，继续 `sudo modprobe yt6801`。



### 2. `ip link show`
- 列出 **系统里所有网络接口**（包括没插线的）。
**目的**：看 YT6801 对应的“有线网卡”是否已经出现。
**正常**会多出一行，名字可能是：

```
2: enp5s0: <BROADCAST,MULTICAST> ...
```

或 `eth0`、`eno1` 等。只要 **有这一行** 就说明硬件已识别，驱动正常。



### 3. `sudo dhclient -v enp5s0`
- `dhclient` 是 **DHCP 客户端**，负责向路由器“要”IP 地址。
- `-v` 把过程打出来，方便你看有没有拿到地址。
- `enp5s0` 是第二步看到的接口名，**替换成你实际的那一行名字**。
**成功输出**末尾会出现：

```
bound to 192.168.x.x -- renewal in 3600 seconds
```

这就代表网线已连、IP 已拿到，可以直接上网了。
