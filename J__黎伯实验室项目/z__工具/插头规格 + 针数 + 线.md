## 插头规格 + 针数 + 线

比如：

```text
GH1.25 2P 单头端子线
```
![[Pasted image 20260807225528.png]]
意思是：

```text
GH：插头系列/外形类型
1.25：针距 1.25mm
2P：2 Pin，两根线/两个孔
单头：只有一端带插头，另一端是裸线或预剥线
```

你图里几个常见规格：

```text
XH2.54：针距 2.54mm，比较大，常见在风扇/开发板排针
PH2.0：针距 2.0mm，中等
GH1.25 / MX1.25：针距 1.25mm，很小
```

`2P/3P/4P/5P/6P-12P` 是针数：

```text
2P = 2根线
3P = 3根线
4P = 4根线
5P = 5根线
...
12P = 12根线
```

`公母线 / 母头线`：

```text
母头线：插孔，通常插到公针上
公头线：有针，插进母座里
公母对插：一边公头，一边母头，可以互相插
```

`单头`：

```text
一端有插头
另一端是散线/裸线
```

`双头`：

```text
两端都有插头
```

XH2.54 2P

#### 场景

如果你是要接香橙派 40Pin 排针，通常买：

```text
杜邦母头 2.54mm
```

如果你是接小风扇自带插座，要看风扇插座间距，常见是：

```text
PH2.0 2P
XH2.54 2P
GH1.25 2P
```
