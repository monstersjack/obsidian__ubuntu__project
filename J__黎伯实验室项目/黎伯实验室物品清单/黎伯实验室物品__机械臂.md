## reBot Arm B601 和，LeRobot，比较

**reBot Arm B601 是机械臂硬件，LeRobot 是机器人学习软件框架**，二者不是竞争产品。实际系统通常是：

`摄像头/主臂 → LeRobot 数据采集与模型训练 → B601 执行动作`



## 黎老师做的ar2 robot arm机械臂

Annin Robotics 的 AR2：一款开源、桌面级、6 轴关节机械臂。外形模仿工业六轴机器人，但采用步进电机、行星减速器、Arduino Mega 和独立步进驱动器，成本与实现门槛远低于工业伺服机械臂。结构可以用铝合金加工件，也可以用高填充率 3D 打印件制作

你老师搭建的“特别大块”版本，很可能就是原始 AR2/AR2 Gen2，而不是后来体积更紧凑的 AR3、AR4。尤其是 J2 肩关节的 NEMA 23 电机加 50:1 行星减速器，确实是一大坨。




####  1. 基本性能

官方 AR2 文档给出的参数是：

| 参数     |              官方数值 | 实际理解                      |
| ------ | ----------------: | ------------------------- |
| 自由度    |               6 轴 | J1～J6，对应工业机械臂的底座、肩、肘和三轴腕部 |
| 最大臂展   | 24.75 英寸，约 629 mm | 从底座到末端的最大伸展距离             |
| 额定负载   |  4.15 lb，约 1.9 kg | 通常指靠近合理姿态时；完全伸直时应降低负载     |
| 标称精度   |           0.01 mm | 更接近软件计算分辨率，不应当理解为真实加工精度   |
| 重复定位精度 |           0.75 mm | 更能代表实际机械性能                |
| 驱动形式   |            开环步进电机 | 原版没有编码器位置闭环               |
| 控制器    |      Arduino Mega | 负责向每个驱动器发送脉冲和方向信号         |
| 主电源    |           24 V DC | 给各轴步进驱动器供电                |
| 回零检测   |         6 个机械限位开关 | 每个关节一个，用于启动校准             |

这些指标来自仓库中的 [AR2 Documentation & Troubleshooting](https://github.com/Chris-Annin/AR2/blob/master/Manual%20-%20AR2%20Documentation%20%26%20Troubleshooting.pdf)。

需要注意：AR2 的真实重复精度受到减速器回差、同步带/链条间隙、3D 打印件刚度、步进丢步和负载挠度影响，不能把“0.01 mm”当成工业机器人那种经过标定的绝对精度。

####  2. 六个关节分别使用什么电机

官方原始 BOM 如下：

| 关节 | 作用 | 电机型号 | 规格 | 减速形式 | 驱动电流设置 |
|---|---|---|---|---|---:|
| J1 | 底座旋转 | `17HS15-1684S-HG20` | NEMA 17，机身约39 mm | 20:1 精密行星减速器，外加同步带 | 1.46 A |
| J2 | 肩关节 | `23HS22-2804S-HG50` | NEMA 23，机身约56 mm | 50:1 精密行星减速器，直接驱动肩轴 | 2.37 A |
| J3 | 肘关节 | `17HS15-1684S-HG50` | NEMA 17，约39 mm | 50:1 精密行星减速器，外加链传动 | 1.46 A |
| J4 | 手腕旋转 | `11HS20-0674S-PG14` | NEMA 11，约51 mm | 约14:1 行星减速器，外加同步带 | 0.5 A |
| J5 | 手腕俯仰 | `17LS19-1684E-200G` | NEMA 17 外置丝杆电机 | 8 mm 导程、约200 mm 丝杆，带动同步带机构 | 1.46 A |
| J6 | 末端旋转 | `14HS13-0804S-PG19` | NEMA 14，约33 mm | 约19:1 行星减速器 | 1.0 A |

电机型号和装配方式可在官方 [AR2 Robot Arm Assembly Manual](https://github.com/Chris-Annin/AR2/blob/master/Manual%20-%20AR2%20Robot%20Arm%20Assembly.pdf) 中核对。

#####  那个“特别大块”的电机是什么？

最可能是 J2：

```text
23HS22-2804S-HG50
```

它由两部分串在一起：

```text
NEMA 23 步进电机 → 50:1 行星减速器 → J2肩关节
```

NEMA 23 电机法兰约为 `57 × 57 mm`，再接一段直径接近电机法兰的金属行星减速箱，所以整体非常粗、非常长，也明显比现在常见的小型舵机机械臂更重。

它必须做得大，原因是 J2 承受的力矩最大：

- 要抬起 J3～J6 整段机械臂；
- 还要抬末端夹爪和负载；
- 机械臂伸直时力臂接近最大；
- 步进电机本身高速扭矩下降明显，因此需要大减速比。

其次可能是 J1 或 J3。它们虽然是 NEMA 17，但同样装有一整段金属行星减速器，所以也比普通3D打印机上的 NEMA 17 大很多。

####  3. 为什么减速箱比电机还显眼

AR2 使用的不是裸步进电机，而是“步进电机 + 行星减速器”。

减速器主要做三件事：

1. 降低输出速度；
2. 按减速比放大输出扭矩；
3. 提高输出端的理论角度分辨率。

例如 J2 使用 50:1 减速器。假设电机是典型的 `1.8°/步`：

```text
减速后的理论整步角度 = 1.8° ÷ 50 = 0.036°
```

再采用半步驱动，理论脉冲分辨率约为：

```text
0.036° ÷ 2 = 0.018°/脉冲
```

但这不等于真实定位精度。真实位置还受减速器回差、结构变形和步进电机失步影响。

原版 J1～J3 采用 HG 精密行星减速器；部分小关节采用 PG 经济型行星减速器。PG 系列一般回差更大，因此手腕部分更容易出现细小晃动。

####  4. 机械传动结构

AR2 并不是六个电机全部直接装在关节中心：

- J1：行星减速电机通过同步带驱动底座主轴。
- J2：大型 NEMA 23 + 50:1 减速器直接连接肩部主轴。
- J3：减速电机通过链条和链轮驱动肘部。
- J4：小型减速电机通过 XL 同步带驱动腕部旋转轴。
- J5：丝杆电机推动直线滑块，再由同步带改变腕部俯仰角。
- J6：小型减速电机直接驱动末端法兰旋转。

这种设计能把一些电机放在相对靠后的地方，但传动带、链条和丝杆也会引入回差与弹性。

####  5. 控制箱里的主要配件

原版电气系统包括：

| 配件                | 数量/用途                 |
| ----------------- | --------------------- |
| Arduino Mega 2560 | 1 块，发送各轴 STEP/DIR 信号  |
| DM542T 步进驱动器      | 5 个，用于 J1、J2、J3、J5、J6 |
| DM320T 步进驱动器      | 1 个，用于较小的 J4          |
| 24 V DC 电源        | 为步进驱动器和电机供电           |
| 5 V DC 辅助电源       | 为继电器板等低压设备供电          |
| 8 路继电器板           | 控制夹爪、电磁阀或其他末端执行器      |
| 急停按钮              | 切断驱动部分的24 V供电         |
| 机械限位开关            | 每个关节一个，用于回零           |
| GX航空插头            | 连接六个关节电机              |
| RJ45/多芯线束         | 连接限位开关与控制箱            |
| DIN导轨、端子排、保险电源入口  | 控制箱配电和保护              |

具体接线与 DIP 开关配置见官方 [AR2 Electrical Enclosure Manual](https://github.com/Chris-Annin/AR2/blob/master/Manual%20-%20AR2%20Electrical%20Enclosure.pdf)。

####  6. 机械本体的主要配件

除了电机，还有这些关键件：

- 铝合金加工件或高填充率3D打印结构件；
- 圆锥滚子轴承；
- 针状滚子轴承；
- 推力轴承和轴承垫片；
- XL 系列同步带和同步带轮；
- J3 链条与链轮；
- J5 丝杆、POM 丝杆螺母和直线滑块；
- 各轴机械限位开关；
- 铝管和关节主轴；
- 末端工具法兰；
- 手册示例中的 SMC `MHF2-8D1` 气动夹爪；
- 可选第七轴直线轨道。

如果老师那台全身都是厚重的银色金属件，它应该采用了铝合金加工套件；如果主体很大但表面有明显打印层纹，则是早期3D打印版。手册要求普通结构件至少约50%填充，传动主轴、张紧环等高受力件达到90%以上填充。

####  7. 它和现代协作机械臂的区别

AR2更像“低成本教学版工业机械臂骨架”：

- 优点：完全开源、结构直观、配件容易理解、适合学习正逆运动学和运动编程。
- 缺点：开环步进容易丢步；没有关节力矩检测；减速器和带/链传动存在回差；不具备碰撞检测；不适合在人旁边高速运行。
- 它不是力控协作臂，也不适合直接徒手拖动示教。
- 断电后位置可能变化，重新上电一般需要通过六个限位开关重新校准。
