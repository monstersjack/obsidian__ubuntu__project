主臂（Leader / 主控臂）和从臂（Follower / 随动臂）是主从遥操作系统的两个核心组成部分，简单说就是「人手操作主臂，从臂同步复刻动作」，是机械臂遥操作、示教采集数据的标准架构。


## reBot Arm B601 和，LeRobot，比较

**reBot Arm B601 是机械臂硬件，LeRobot 是机器人学习软件框架**，二者不是竞争产品。实际系统通常是：

`摄像头/主臂 → LeRobot 数据采集与模型训练 → B601 执行动作`

####  二、关节电机性能对比

以下SO-101参数按开源仓库使用的**标准7.4V STS3215版本**比较；Seeed的12V Pro套件使用不同舵机版本，不能完全套用这一列。

| 电机参数 | SO-101 Follower：STS3215 | B601大关节：DM4340P | B601腕部/夹爪：DM4310 |
|---|---:|---:|---:|
| 使用数量 | 6个 | 3个，J1～J3 | 4个，J4～J6＋夹爪 |
| 电机形式 | 有刷核心电机 | 无刷关节模组 | 无刷关节模组 |
| 典型电压 | 7.4V | 24V | 24V |
| 减速比 | 345:1 | 40:1 | 10:1 |
| 额定转矩 | 5kg·cm，约0.49N·m | 9N·m | 3N·m |
| 峰值/堵转转矩 | 19.5kg·cm，约1.91N·m | 27N·m | 7N·m |
| 额定转速 | 未单独给出 | 36rpm | 120rpm |
| 空载速度 | 0.192秒/60°，约52rpm | 52rpm | 200rpm |
| 额定电流 | 约0.65A | 2.5A | 2.5A |
| 峰值/堵转电流 | 约2.5A | 8A | 7.5A |
| 编码器 | 单12位磁编码器 | 双14位磁编码器 | 双14位磁编码器 |
| 编码器量化 | 0.088°/计数 | 约0.022°/计数 | 约0.022°/计数 |
| 公开齿隙 | ≤0.5° | 未在整机资料中明确 | 未在整机资料中明确 |
| 电机重量 | 55±1g | 约375g | 约300g |
| 通信 | UART，最高1Mbps | CAN 1Mbps | CAN 1Mbps |

| 状态反馈 | 位置、速度、负载、电流、电压、温度 | 位置、速度、转矩、温度等 | 位置、速度、转矩、温度等 |

STS3215的详细数据见[飞特官方规格书](https://files.seeedstudio.com/wiki/reComputer-Jetson/lerobot/STS3215-C001-20230624.pdf)；DM4310参数见[达妙DM-J4310说明书](https://files.seeedstudio.com/products/Damiao/DM-J4310-en.pdf)，DM4340P参数见[达妙产品参数页](https://damiao.enactic.ai/en/products/hardware/dm-j4340p-2ec-v1.0/)。

最明显的差异是：B601肩部电机的额定转矩约为标准SO-101舵机的**18倍**，峰值转矩约为**14倍**。但转矩比不能直接换算成整机负载比，因为还涉及臂长、自重、结构刚性和工作姿态。

| 急停         | 通常靠断电或自行增加         | 强烈建议配置物理急停              |


####  “精细度”应该怎么理解

#####  1. B601的±0.1/±0.2 mm是重复定位精度

它表示机械臂多次返回同一个目标位置时的离散程度，并不等于：

- 绝对定位误差；
- 轨迹跟踪误差；
- 视觉抓取误差；
- AI模型执行成功率。

因此，B601-RS宣传的±0.1 mm不能直接理解为“能够把零件精确插入0.1 mm间隙”。实际还会受到末端负载、夹爪间隙、结构挠度、标定和视觉误差影响。目前公开资料中没有看到完整的ISO 9283第三方测试报告。

#####  2. SO-101的12位编码器不等于整机精度

12位编码器理论上每圈有4096个位置：

`360° ÷ 4096 ≈ 0.088°/计数`

这只是传感器量化分辨率。经过舵机齿轮间隙、塑料结构弹性、负载变形和多个关节误差叠加后，末端实际精度会低得多，所以不能拿“0.088°”直接对比B601的“±0.2 mm”。

#####  3. LeRobot没有固定的“精度参数”

LeRobot提供的是：

- 遥操作和数据采集；
- 数据集管理；
- ACT、SmolVLA、π₀等策略训练；
- 模型推理、回放和评估；
- 单臂、双臂控制；
- 多种机器人硬件接口。

它本身没有负载、臂展或重复定位精度。AI操作精度取决于机械臂、摄像头、手眼标定、训练数据质量、模型和任务难度。[LeRobot官方说明](https://huggingface.co/docs/lerobot/index)也将其定义为真实机器人上的模型、数据集和训练工具框架。



####  B601接入LeRobot的成熟度

B601-DM 已经出现在 Hugging Face 官方机器人列表中，提供：

- `rebot_b601_follower` 单臂；
- `bi_rebot_b601_follower` 双臂；
- reBot Arm 102主臂遥操作；
- Damiao CAN和SocketCAN支持。

## 黎老师做的ar2 robot arm机械臂

Annin Robotics 的 AR2：一款开源、桌面级、6 轴关节机械臂。外形模仿工业六轴机器人，但采用步进电机、行星减速器、Arduino Mega 和独立步进驱动器，成本与实现门槛远低于工业伺服机械臂。结构可以用铝合金加工件，也可以用高填充率 3D 打印件制作

你老师搭建的“特别大块”版本，很可能就是原始 AR2/AR2 Gen2，而不是后来体积更紧凑的 AR3、AR4。尤其是 J2 肩关节的 NEMA 23 电机加 50:1 行星减速器，确实是一大坨。




####  1. 基本性能

官方 AR2 文档给出的参数是：

#####  那个“特别大块”的电机是什么？

最可能是 J2：

```text
23HS22-2804S-HG50
```

它由两部分串在一起：

```text
NEMA 23 步进电机 → 50:1 行星减速器 → J2肩关节
```

NEMA 23 电机法兰约为 `57 × 57 mm`，再接一段直径接近电机法兰的金属行星减速箱，所以整体非常粗、非常长，也明显比现在常见的小型舵机机械臂更重。

它必须做得大，原因是 J2 承受的力矩最大：

- 要抬起 J3～J6 整段机械臂；
- 还要抬末端夹爪和负载；
- 机械臂伸直时力臂接近最大；
- 步进电机本身高速扭矩下降明显，因此需要大减速比。

其次可能是 J1 或 J3。它们虽然是 NEMA 17，但同样装有一整段金属行星减速器，所以也比普通3D打印机上的 NEMA 17 大很多。

####  3. 为什么减速箱比电机还显眼

AR2 使用的不是裸步进电机，而是“步进电机 + 行星减速器”。

减速器主要做三件事：

1. 降低输出速度；
2. 按减速比放大输出扭矩；
3. 提高输出端的理论角度分辨率。

例如 J2 使用 50:1 减速器。假设电机是典型的 `1.8°/步`：

```text
减速后的理论整步角度 = 1.8° ÷ 50 = 0.036°
```

再采用半步驱动，理论脉冲分辨率约为：

```text
0.036° ÷ 2 = 0.018°/脉冲
```

但这不等于真实定位精度。真实位置还受减速器回差、结构变形和步进电机失步影响。

原版 J1～J3 采用 HG 精密行星减速器；部分小关节采用 PG 经济型行星减速器。PG 系列一般回差更大，因此手腕部分更容易出现细小晃动。

####  4. 机械传动结构

AR2 并不是六个电机全部直接装在关节中心：

- J1：行星减速电机通过同步带驱动底座主轴。
- J2：大型 NEMA 23 + 50:1 减速器直接连接肩部主轴。
- J3：减速电机通过链条和链轮驱动肘部。
- J4：小型减速电机通过 XL 同步带驱动腕部旋转轴。
- J5：丝杆电机推动直线滑块，再由同步带改变腕部俯仰角。
- J6：小型减速电机直接驱动末端法兰旋转。

这种设计能把一些电机放在相对靠后的地方，但传动带、链条和丝杆也会引入回差与弹性。

####  7. 它和现代协作机械臂的区别

AR2更像“低成本教学版工业机械臂骨架”：

- 优点：完全开源、结构直观、配件容易理解、适合学习正逆运动学和运动编程。
- 缺点：开环步进容易丢步；没有关节力矩检测；减速器和带/链传动存在回差；不具备碰撞检测；不适合在人旁边高速运行。
- 它不是力控协作臂，也不适合直接徒手拖动示教。
- 断电后位置可能变化，重新上电一般需要通过六个限位开关重新校准。
