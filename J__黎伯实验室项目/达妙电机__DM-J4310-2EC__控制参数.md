## 这是达妙 DM 电机的 CAN 调试界面。
红框和右侧参数主要用于控制电机状态、生成控制帧。

#####  红框按钮

- **电机使能**：让驱动器进入闭环工作状态[^1]，开始响应位置、速度或转矩指令。使能不等于一定旋转，但此时电机可以输出力矩。
- **保存零点**：把电机当前机械位置设为新的 `0 rad`。它不是让电机自动转回零位；一般应先失能、手动放到期望零位后再操作。
- **电机失能**：停止闭环力矩输出，轴通常会变松。若电机承载重物，失能后负载可能掉落。
- **电机已使能**：这是反馈状态，表示驱动器当前确实处于使能状态。
- **CAN 数据帧**：显示软件准备发送的原始 8 字节 CAN 数据。

#####  CAN ID

| 参数           | 含义                                 |
| ------------ | ---------------------------------- |
| `CAN ID = 1` | 电机接收控制命令所使用的 CAN ID，即电机ID          |
| `MST ID = 2` | ==电机发送状态反馈==所使用的 CAN ID，即反馈ID/主机ID |

因此当前通常是：上位机向 `0x001` 发送命令，电机使用 `0x002` 返回位置、速度、转矩和温度。两者都是标准 CAN ID，范围通常为 `0～0x7FF`。

#####  MIT 模式参数

MIT 是一种==位置、速度和转矩==混合控制模式，基本控制关系为：

```text
输出转矩 =
Kp ×（目标位置 − 实际位置）
+ Kd ×（目标速度 − 实际速度）
+ 前馈转矩
```

| 参数              | 含义                                 |
| --------------- | ---------------------------------- |
| **位置 Position** | 目标位置，单位 `rad`。`1 rad≈57.3°`        |
| **速度 Velocity** | 目标速度，单位 `rad/s`                    |
| **KP**          | 位置刚度。越大，电机越强硬地追踪目标位置；过大会振荡         |
| **KD**          | 速度阻尼。用于抑制振荡；过小容易抖动，过大反应迟钝          |
| **转矩 Torque**   | 前馈转矩 `t_ff`，单位 `N·m`，可以直接提供推力或补偿负载 |

####  九、MIN/MAX 范围到底代表什么

| 参数 | 编码范围 | 含义 |
|---|---:|---|
| Position | `-12.5～12.5 rad` | CAN 能表示的位置区间 |
| Velocity | `-30～30 rad/s` | CAN 能表示的速度区间 |
| KP | `0～500` | Kp 的编码区间 |
| KD | `0～5` | Kd 的编码区间 |
| Torque | `-10～10 N·m` | CAN 能表示的前馈转矩区间 |

这些 MIN/MAX 主要是 **CAN 数值映射范围**，不一定等于电机实际允许的机械极限或安全极限。位置控制时不要让 `KD=0`，官方说明指出这可能导致振荡甚至失控。[达妙中文说明书](https://damiao.enactic.ai/assets/files/dm-j4310-2ec-v1.1-zh-5d089e0b013d8e2fc203c5b670008a66.pdf)

#####  `7F FF 7F F0 00 00 07 FF` 是什么意思

MIT 协议把五个参数压缩进一个 8 字节 CAN 帧：

```text
D0 D1       ：位置，16位
D2 + D3高4位：速度，12位
D3低4位+D4 ：KP，12位
D5 + D6高4位：KD，12位
D6低4位+D7 ：转矩，12位
```

当前数据可以拆成：

```text
位置 = 0x7FFF ≈ 0 rad
速度 = 0x7FF  ≈ 0 rad/s
KP   = 0x000  = 0
KD   = 0x000  = 0
转矩 = 0x7FF  ≈ 0 N·m
```

所以它实际表示“所有控制量接近零”，不是大数值。因为位置、速度、转矩允许正负数，而 CAN 中采用无符号整数映射，所以零点位于编码范围中间。

#####  其他模式和状态

- **MIT**：位置、速度、刚度、阻尼、转矩综合控制。
- **位置**：给目标位置和运动速度上限，电机自行完成位置闭环。
- **速度**：让电机持续运行在指定速度。
- **PVT**：该版本通常表示位置、速度、转矩综合/力位混合控制，具体帧格式要以对应电机型号和固件协议为准。
- **周期位置/速度/扭矩**：用于自动产生周期测试指令，电机可能连续往复或旋转。
- 三幅曲线分别是实际位置、实际速度和实际转矩。
- **电机温度/驱动温度**：分别监测绕组和驱动功率器件温度。
- **定时发送 1 ms**：每 `1 ms` 发一次控制帧，即理论上 `1000 Hz`。
- 左侧 `921600` 是电脑与 USB-CAN 工具的串口波特率；底部 `电机波特率 1.00M` 是实际 CAN 总线速率，两者不是同一个参数。

特别注意：使能前最好先保持 `KP=0、KD=0、转矩=0`。如果目标位置为零且突然给较大的 KP，电机可能立即快速转向保存的零点。


**电流和转矩不是同一个物理量，但在电机正常工作范围内，转矩通常与“转矩电流”近似成正比。**

```text
电流越大 → 电磁作用越强 → 转矩越大
```

#### 电流方向也决定转矩方向

通常：

```text
正电流 → 正方向转矩
负电流 → 负方向转矩
```

## 理解MIT 模式

先抓住最核心的一点：MIT 模式的五个参数会共同计算出一个“电机应该输出多少转矩”。

正确的常见 MIT 控制关系是：
$$
\boxed{\tau_{\rm cmd}
=K_p(p_{\rm des}-p)
+K_d(v_{\rm des}-v)
+t_{\rm ff}}
$$

也可以写成：
$$
\tau_{\rm cmd}
=K_p(p_{\rm des}-p)
-K_d(v-v_{\rm des})
+t_{\rm ff}
$$


#### 参数理解
- ==目标位置== `p_des` 是弹簧固定点。
- `Kp` 是==弹簧硬度==。
- ==目标速度== `v_des` 是减震器希望达到的运动速度。
- `Kd` 是==减震强度==。
- `t_ff` 是不经过位置、速度误差计算，直接加上的==转矩==。


cmd 是 command 的缩写，意思是“指令”或“命令”。
因此：
$$
\tau_{\rm cmd}
$$
表示：
电机驱动器计算得到的==目标转矩指令==。



官方说明也明确指出：
`Kp=0、Kd≠0`时可以做速度控制；
`Kp=Kd=0`时，`t_ff`直接产生转矩；
位置控制时 `Kd` 不能设为零。

### 概念理解

#### 转矩和扭矩是什么意思

**转矩（Torque）就是让物体绕轴旋转的“拧动力量”**，也常叫“扭矩”，符号是 $\tau$，单位是 **N·m（牛·米）**。

简单理解：

- 转矩越大，电机越有力，越能推动重物或抵抗外力。
- 正转矩使电机向规定的正方向转。
- 负转矩使电机向反方向转或起制动作用。
- 转矩为零表示电机不主动“拧”轴，但轴仍可能因惯性或外力转动。

计算关系：

$$
\tau=F\times r
$$


其中：

- $F$：施加的力，单位 N
- $r$：力到旋转中心的垂直距离，单位 m

例如，在长度为 `0.2 m` 的扳手末端施加 `10 N` 的力：

$$
\tau=10\times0.2=2\ {\rm N\cdot m}
$$


这就产生了 `2 N·m` 的转矩。

在电机中，转矩就是电机轴输出的“旋转推动力”。例如电机输出 `3 N·m`，在半径 `0.1 m` 的轮子边缘，理论推力约为：

$$
F=\frac{\tau}{r}=\frac{3}{0.1}=30\ {\rm N}
$$




###  MIT的原理，把它想象成“弹簧＋减震器＋额外推力”

MIT 控制可以用一个机械模型理解：

- `Position + KP`：一根虚拟弹簧。
- `Velocity + KD`：一个虚拟减震器。
- `Torque`：你额外用手推它一把。

其中：

- 目标位置 `p_des` 是弹簧固定点。
- `Kp` 是弹簧硬度。
- 目标速度 `v_des` 是减震器希望达到的运动速度。
- `Kd` 是减震强度。
- `t_ff` 是不经过位置、速度误差计算，直接加上的转矩。

最终三部分转矩相加，再由驱动器的电流环执行。

---




####  三、KP：虚拟弹簧的硬度

`Kp` 决定“每相差一弧度，要产生多少转矩”。

它的实际单位可以理解为：

```text
N·m/rad
```

软件界面中的 `N/r` 属于不太完整的简写。

例如位置误差都是 `0.1 rad≈5.73°`：

|  KP |   位置项转矩 | 感觉                |
| --: | ------: | ----------------- |
|   1 | 0.1 N·m | 很软                |
|   5 | 0.5 N·m | 比较柔顺              |
|  20 |   2 N·m | 明显变硬              |
| 100 |  10 N·m | 非常强，可能已经超过电机能力    |
| 500 |  50 N·m | 只是协议允许编码，不代表电机能输出 |

所以 `KP=500` 并不表示电机真的能够输出几百牛米。驱动器最终还会受到电流限制、峰值转矩和保护参数限制。

另外，Kp 越大：

- 位置误差稍微变化，就会产生很大转矩。
- 电机看起来越“硬”。
- 响应通常更快。
- 但更容易产生振动、冲击、啸叫和过流。

---


####  五、KD：速度阻尼或速度增益

`Kd` 决定“每相差 1 rad/s，要产生多少转矩”。

它的单位可以理解为：

```text
N·m·s/rad
```

当目标速度设为零时：
$$
\tau_v=K_d(0-v)=-K_dv
$$

这说明它总是产生与实际运动方向相反的转矩，因此像减震器一样**抑制振荡**。

例如：

```text
目标速度 = 0
实际速度 = 2 rad/s
KD = 0.5
```

那么：

```text
速度项转矩 = 0.5 × (0 - 2)
           = -1 N·m
```

这相当于给电机施加 `1 N·m` 的反向制动力。

所以在位置控制中：

- `KP` 把电机拉向目标位置。
- `KD` 防止电机冲过头、来回摆动。

如果只有 KP、没有 KD，就像“弹簧没有减震器”，电机可能在目标位置两边不停振荡。官方因此明确警告：MIT 位置控制时不要让 `Kd=0`。[DM-J4310 MIT 模式说明](https://damiao.enactic.ai/en/products/hardware/dm-j4310-2ec-v1.1/)

不过 KD 也不是越大越好：

- 太小：压不住振荡。
- 太大：反应迟钝，运动阻力很强。
- 很大时还可能放大速度测量噪声，导致转矩抖动。

#### 完整理解KD和KP


最简单的理解是：

> **KP 看“位置差多少”，KD 看“现在冲得有多快”。**

先把目标速度设为 `0`、前馈转矩设为 `0`，公式就简化成：
$$
\boxed{\tau=K_p(p_{\rm des}-p)-K_dv}
$$

也就是：

```text
最终转矩 = 拉回目标位置的转矩 + 阻止快速运动的转矩
```

#####   KP：像橡皮筋或弹簧

想象电机轴和目标位置之间连着一根虚拟弹簧：

- 电机离目标越远，弹簧拉力越大。
- 电机离目标越近，弹簧拉力越小。
- 电机正好在目标位置，弹簧不再用力。
- `KP` 越大，弹簧越硬。

计算公式：
$$
\tau_p=K_p(p_{\rm des}-p)
$$

假设：

```text
目标位置 = 1 rad
实际位置 = 0.8 rad
KP = 2 N·m/rad
```

则：

```text
位置误差 = 1 - 0.8 = 0.2 rad
KP产生的转矩 = 2 × 0.2 = 0.4 N·m
```

电机受到正方向 `0.4 N·m` 的转矩，向目标位置运动。

如果电机超过目标：

```text
目标位置 = 1 rad
实际位置 = 1.1 rad
KP = 2
```

则：

```text
位置误差 = 1 - 1.1 = -0.1 rad
KP产生的转矩 = 2 × (-0.1)
             = -0.2 N·m
```

负号表示反方向，电机会被重新拉回目标位置。

所以可以记成：

> **KP 负责“把电机拉到哪里”。**

---

#####   KD：像门上的缓冲器

只有弹簧还不够。

想象一扇装有弹簧的门。如果没有缓冲器，门可能：

```text
冲过目标 → 被拉回来 → 又冲过目标 → 来回振荡
```

KD 就像门上的液压缓冲器：

- 运动得越快，反向阻力越大。
- 运动得越慢，阻力越小。
- 完全不动时，阻力为零。
- `KD` 越大，缓冲作用越强。

当目标速度为零时：
$$
\tau_d=-K_dv
$$

假设电机正方向运动：

```text
实际速度 = +2 rad/s
KD = 0.5
```

那么：

```text
KD产生的转矩 = -0.5 × 2
             = -1 N·m
```

电机正方向运动，KD 产生负方向转矩，因此它在刹车。

如果电机向负方向运动：

```text
实际速度 = -2 rad/s
KD = 0.5
```

那么：

```text
KD产生的转矩 = -0.5 × (-2)
             = +1 N·m
```

电机向负方向运动，KD 产生正方向转矩，仍然是在刹车。

所以可以记成：

> **KD 负责“别冲得太快，别来回振荡”。**

---



####  四、Velocity：目标速度

单位是 `rad/s`，即每秒转过多少弧度：
$$
{\rm rpm}={\rm rad/s}\times\frac{60}{2\pi}
$$




####  六、Torque：前馈转矩

这个 Torque 是：
$$
t_{\rm ff}
$$

也就是直接叠加到最终命令上的前馈转矩：
$$
\tau_{\rm cmd}=\tau_p+\tau_v+t_{\rm ff}
$$

它不是“最大转矩限制”。

例如：

```text
位置项 = 2 N·m
速度项 = -0.5 N·m
前馈转矩 = 0.8 N·m
```

最终命令为：

```text
2 - 0.5 + 0.8 = 2.3 N·m
```

常见用途包括：

- 直接进行转矩控制。
- 补偿机械摩擦。
- 补偿机械臂重力。
- 在位置控制之外额外提供推力。


####  七、五个参数怎样组合

#####  1. 保持位置

```text
Position = 需要保持的位置
Velocity = 0
KP > 0
KD > 0
Torque = 0
```

含义是：

- KP 把电机拉回目标位置。
- KD 抑制运动和振荡。
- 最终像一个带减震器的弹簧。

#####  2. 纯速度控制

```text
Position = 任意
Velocity = 目标速度
KP = 0
KD > 0
Torque = 0
```

因为 `KP=0`，Position 被忽略：
$$
\tau_{\rm cmd}=K_d(v_{\rm des}-v)
$$

#####  3. 纯转矩控制

```text
KP = 0
KD = 0
Torque = 目标转矩
```

Position 和 Velocity 都被忽略：
$$
\tau_{\rm cmd}=t_{\rm ff}
$$

#####  4. 轨迹控制

控制器每隔例如 `1 ms` 更新一次：

```text
Position = 当前轨迹目标位置
Velocity = 当前轨迹目标速度
KP、KD = 需要的刚度和阻尼
Torque = 重力或动力学补偿
```

这种情况下，目标位置和目标速度会随时间一起变化，而不是始终固定。

## 理解PVT模式

> 在达妙这个调试工具中，`PVT` 通常可以按 `Position–Velocity–Torque` 理解，但它实际对应的是“力位混合控制”。其中 `V` 是速度上限，`T` 更准确地说是转矩电流上限，不是三个独立目标，也不是“位置—速度—时间轨迹”。

官方协议把 PVT/力位混控帧定义为：

```text
目标位置 p_des
速度上限 v_des
电流/转矩上限 i_des
```

不是 MIT 模式中的：

```text
目标位置 + 目标速度 + KP + KD + 前馈转矩
```

####  一、PVT 的内部工作过程

PVT 可以理解为一个带“速度限制”和“力量限制”的自动位置控制器：

```text
目标位置
   ↓
位置控制器
   ↓
速度命令 ──受到 V 限制
   ↓
速度控制器
   ↓
电流命令 ──受到 T/i_des 限制
   ↓
电流环
   ↓
电机输出转矩
```

近似可以写成：

```text
速度命令 =
位置控制器（目标位置－实际位置）

速度命令 =
限制在 ±速度上限以内

电流命令 =
速度控制器（速度命令－实际速度）

电流命令 =
限制在 ±电流上限以内
```

最终电机转矩大致与电流成正比：
$$
\tau \approx K_t I
$$

因此 PVT 的意思可以直观理解为：

> “去这个位置，但路上不要超过这个速度，而且用力不要超过这个上限。”

这正是“力位混合”的含义。


P：目标位置 Position
V：速度上限 Velocity Limit
T：转矩/电流上限


####  五、PVT 的 CAN 帧

有力位混控支持的达妙协议通常使用：

```text
CAN ID = 0x300 + 电机 CAN ID
```

如果电机 ID 是：

```text
CAN ID = 1
```

那么 PVT 控制帧 ID 通常为：

```text
0x301
```

8 字节数据排列如下：

```text
D0～D3：p_des，32位 float，小端序
D4～D5：v_des × 100，无符号16位，小端序
D6～D7：i_des × 10000，无符号16位，小端序
```

## 比较表格

#### 2. 电机实际会怎样运动

| 模式       | 启动后的行为                | 到位后会怎样                  | 遇到阻挡会怎样                  | 控制感觉               |
| -------- | --------------------- | ----------------------- | ------------------------ | ------------------ |
| MIT      | 根据P、V、KP、KD、Tff立即计算输出 | `KP>0`时会保持目标位置；KP越大越“硬” | 继续按设定刚度和前馈力矩出力           | 可硬、可软，反应最快，但参数最复杂  |
| 位置速度     | 按设定加速度和限速运动到目标位置      | 内部位置环保持目标位置             | 位置误差一直存在时可能持续增加输出        | 平滑、稳定，适合普通定位       |
| 速度       | 不断调整输出，使速度接近设定值       | 不存在“到位”；会持续旋转           | 负载增大时自动增加转矩，直至达到电流限制     | 类似定速巡航             |
| PVT/力位混控 | 向目标位置运动，但速度和电流均受限制    | 尝试保持位置，但不会超过电流上限        | 达到电流上限后可能停在障碍物处，不再猛烈增加输出 | 比普通位置模式更柔和、更适合接触物体 |

#### 3. 优点、缺点和适用场景

| 模式       | 最适合的场景                            | 主要优点                         | 不适合的场景                    | 主要风险                              |
| -------- | --------------------------------- | ---------------------------- | ------------------------- | --------------------------------- |
| MIT      | 机器人关节、机械臂轨迹、足式机器人、阻抗控制、弹簧感、直接转矩实验 | 上位机控制自由度最高，可以实时改变刚度、阻尼和转矩    | 初学者简单定位、只想转到一个角度          | KP过大会猛转，KD过小会振荡；零点错误时可能突然转动       |
| 位置速度     | 点到点定位、舵机式运动、机械臂缓慢移动、云台转角          | 参数少、运动平滑、内部自动完成位置闭环          | 精确力控制、碰撞柔顺、直接转矩控制         | 目标位置或零点错误会朝错误方向运动；遇到阻挡仍可能持续出力     |
| 速度       | 轮子、滚筒、输送带、转盘、风扇、泵、连续旋转机构          | 直接给速度即可，最适合连续旋转              | 精确停在某个角度、保持固定位置           | 给错正负方向会一直反向转；失控时可能持续加速            |
| PVT/力位混控 | 夹爪、压紧机构、柔和归位、推靠限位、接触物体            | 能同时限制速度和最大电流，比普通位置控制更不容易猛烈碰撞 | 精确恒力控制、直接输出正负转矩、快速机器人阻抗控制 | 电流百分比不等于精确夹持力；设太低到不了位置，设太高仍可能夹坏物体 |

## MIT和PVT的根本区别和使用方向


最核心的区别可以记成：

> **PVT：告诉电机“去哪里、别太快、别太用力”，具体怎么走主要由驱动器完成。**
> **MIT：上位机直接规定“虚拟弹簧多硬、减震多强、额外给多少转矩”，运动特性由上位机决定。**

#####  一、PVT 和 MIT 的根本区别

| 对比 | PVT／力位混控 | MIT |
|---|---|---|
| 主要目标 | 到达指定位置，同时限制速度和最大用力 | 按指定刚度、阻尼、前馈转矩运动 |
| 输入 | 位置、速度上限、电流上限 | 位置、目标速度、KP、KD、前馈转矩 |
| 速度参数 | 最大允许速度 | 希望达到的目标速度 |
| 转矩参数 | 最大允许电流/转矩上限 | 直接叠加的前馈转矩 |
| 控制器位置 | 位置环、速度环主要在电机驱动器内部 | 上位机直接决定位置、速度误差产生多少转矩 |
| 调试难度 | 较低 | 较高 |
| 灵活性 | 较低 | 很高 |
| 适合 | 柔和定位、夹爪、压紧、限力运动 | 阻抗控制、机器人关节、动态轨迹、直接转矩控制 |
| 主要优点 | 简单，并且可以限制速度和最大用力 | 能精确设计电机的“软硬程度”和动态行为 |

---

####  二、为什么使用 PVT 模式

PVT 的控制思想是：

```text
我要去某个位置，
但速度不能超过 V，
输出电流不能超过 T。
```

内部过程大致是：

```text
目标位置 P
    ↓
内部位置环
    ↓
生成速度命令
    ↓
限制在 ±V 以内
    ↓
内部速度环
    ↓
生成电流命令
    ↓
限制在 ±T 以内
    ↓
电流环控制电机
```

其中：

- `P`：最终想去的位置。
- `V`：运动过程的最高速度。
- `T/i_des`：最大允许使用的电流比例，间接限制最大转矩。

#####  PVT 的第一个好处：使用简单

假设要让机械臂关节转到 `30°`：

```text
P = 0.524 rad
V = 0.5 rad/s
T = 最大电流的20%
```

你只需要表达：

> “去 30°，速度不要超过 0.5 rad/s，最多使用 20% 电流。”

如何根据位置误差加速、如何接近目标、什么时候减速，主要由驱动器内部的位置环和速度环完成。

而使用 MIT 时，通常还要考虑：

```text
目标位置应该怎样随时间变化？
目标速度应该怎样变化？
KP应该多大？
KD应该多大？
是否需要重力补偿转矩？
总转矩是否需要限制？
```

所以普通定位任务中，PVT 更容易使用。

---

#####  PVT 的第二个好处：可以直接限制最大用力

普通位置控制可能一直尝试到达目标。

例如夹爪目标是：

```text
完全闭合位置 = 0 rad
```

但物体挡在：

```text
0.2 rad
```

夹爪无法到达目标，因此位置误差一直存在。控制器会继续增加电流，试图闭合。

PVT 中可以设置：

```text
电流上限 = 最大电流的10%
```

那么即使位置误差继续增大，内部电流命令也会被限制：

```text
需要30%电流
        ↓
超过上限
        ↓
实际最多允许10%
```

因此夹爪最多使用约 10% 的电流去夹物体，不会因为位置误差很大就无限增加电流。

但要注意：

> 电流上限只是限制电机能使用的最大电流，不等于精确的夹持力。

实际夹持力还受到：

- 电机转矩常数。
- 减速比。
- 减速器效率。
- 机械摩擦。
- 连杆长度。
- 夹爪结构。
- 接触位置。

等因素影响。

---

---

#####  PVT 的第四个好处：对上位机实时性的要求相对较低

PVT 的位置环、速度环和电流环主要在驱动器内部运行。

上位机发送：

```text
目标位置
速度限制
电流限制
```

以后，驱动器会在内部高频执行控制。

因此，电脑发送间隔稍有抖动时，内部控制环仍然可以继续稳定运行。相比之下，MIT 如果需要上位机不断发送高速轨迹、动态 KP/KD 和前馈转矩，对发送周期的稳定性要求更高。

不过 PVT 仍然可能受到通信超时保护影响，不能理解成“只发一次，以后永远不用发送”。

---

#####  PVT 的第五个好处：适合“位置优先、力量受限”的任务

PVT 的基本优先关系是：

```text
首先尝试到达位置
同时不超过速度上限
同时不超过电流上限
```

因此它特别适合：

> “我希望你尽量到这里；如果被挡住，也不要太用力。”

例如夹爪：

```text
没有物体：
夹爪正常到达完全闭合位置

有物体：
夹爪被物体挡住
→ 无法到达目标位置
→ 电流增加
→ 达到电流上限
→ 保持有限夹持力
```

---

#####  PVT 的不足

######  1. 不能直接调节“弹簧软硬”

PVT 内部位置环的参数通常预先配置在驱动器中。

你可以限制最大电流，但不能像 MIT 一样，在每个控制周期直接改变：

```text
KP
KD
```

所以：

```text
PVT的电流上限低
```

不完全等于：

```text
MIT的KP低
```

两者感觉不同：

- MIT 低 KP：偏离一点只产生一点转矩，像软弹簧。
- PVT：可能仍然表现得比较硬，只是在达到电流上限后不再增加力量。

######  2. 被挡住后可能持续发热

如果目标位置一直在障碍物后面：

```text
目标位置无法到达
位置误差持续存在
电流长期达到上限
```

即使电流被限制，电机仍可能持续发热。

因此夹爪或压紧任务通常还需要：

- 接触检测。
- 到达电流阈值后停止增加位置。
- 降低保持电流。
- 设置超时。
- 监测温度。

######  3. 电流限制不是安全力传感器

PVT 能限制用力，但不能代替：

- 急停。
- 机械限位。
- 扭矩传感器。
- 力传感器。
- 安全继电器。
- 防夹结构。

---

####  三、为什么使用 MIT 模式

MIT 的控制公式是：
$$
\tau_{\rm cmd}
=K_p(p_{\rm des}-p)
+K_d(v_{\rm des}-v)
+t_{\rm ff}
$$

它不是简单地说“去某个位置”，而是在每个控制周期直接计算：

> “根据当前的位置误差、速度误差和前馈转矩，现在应该输出多少转矩。”

MIT 的三部分可以理解为：

```text
KP位置项：负责拉向目标位置
KD速度项：负责加速或刹车
Tff前馈项：额外直接增加转矩
```

---

#####  MIT 的第一个好处：可以控制电机的“软硬程度”

这是 MIT 最重要的优势。

假设：

```text
目标位置 = 1 rad
实际位置 = 0.9 rad
位置误差 = 0.1 rad
```

如果：

```text
KP = 2
```

位置项转矩为：

```text
2 × 0.1 = 0.2 N·m
```

电机比较柔软，手可以比较容易地推离目标位置。

如果：

```text
KP = 20
```

则：

```text
20 × 0.1 = 2 N·m
```

同样偏离 `0.1 rad`，恢复转矩增加了十倍，电机感觉更硬。

所以 MIT 可以直接设定：

- 机械臂关节应该柔软还是坚硬。
- 被人推动时让开多少。
- 偏离目标时产生多大恢复力。
- 接触物体时表现得像软弹簧还是硬弹簧。

这种能力称为：

```text
阻抗控制
柔顺控制
虚拟弹簧控制
```

---

#####  MIT 的第二个好处：可以控制阻尼

KP 只负责拉回位置，但没有告诉电机应该怎样停下来。

KD 根据速度产生转矩：
$$
\tau_d=K_d(v_{\rm des}-v)
$$

当目标速度为零时：
$$
\tau_d=-K_dv
$$

因此 KD 会反抗当前运动。

例如电机正快速接近目标：

```text
实际速度 = +2 rad/s
目标速度 = 0
KD = 0.5
```

则：

```text
KD转矩 = 0.5 × (0 - 2)
       = -1 N·m
```

这个负转矩会提前刹车，减少冲过目标后的振荡。

因此 MIT 不只决定“去哪里”，还可以决定：

> “接近目标时应该多快刹车、运动感觉应该多柔和。”

---

#####  MIT 的第三个好处：可以直接进行转矩控制

设置：

```text
KP = 0
KD = 0
t_ff = 1 N·m
```

则：
$$
\tau_{\rm cmd}=1\ {\rm N\cdot m}
$$

这时 Position 和 Velocity 都不起作用，电机主要执行直接转矩命令。

适合：

- 测试电机转矩。
- 轮足机器人关节输出力。
- 重力补偿。
- 主动支撑负载。
- 外部力控制算法。
- 上位机自己实现位置或速度控制器。

PVT 不能这样直接发送一个有正负方向的目标转矩。PVT 的 `T` 主要是电流上限，方向由位置控制器决定。

---

#####  MIT 的第四个好处：可以增加重力补偿

假设机械臂水平伸出时，重力会让关节向下掉。

如果只使用位置控制，KP 必须依靠位置误差产生支撑转矩：

```text
机械臂先向下掉一点
→ 出现位置误差
→ KP产生向上的转矩
→ 最后在一个有误差的位置平衡
```

如果上位机能够计算重力所需转矩：

```text
重力补偿转矩 = 0.8 N·m
```

可以设置：

```text
t_ff = 0.8 N·m
```

这样，即使位置误差接近零，也可以提前提供支撑重力的转矩。

最终：
$$
\tau_{\rm cmd}
=
位置纠错转矩
+
速度阻尼转矩
+
重力补偿转矩
$$

好处是：

- 位置误差更小。
- 不需要单纯依靠很大的 KP 支撑负载。
- 机械臂可以同时保持柔顺。
- 轨迹跟踪通常更准确。

---

#####  MIT 的第五个好处：可以进行高性能轨迹控制

假设机械臂需要平滑运动：

```text
0秒：位置0，速度0
1秒：位置0.5，速度0.8
2秒：位置1.0，速度0
```

上位机可以每隔 `1 ms` 计算并发送：

```text
当前目标位置 p_des(t)
当前目标速度 v_des(t)
当前位置刚度 KP
当前速度阻尼 KD
当前前馈转矩 t_ff(t)
```

这样电机不是突然收到一个很远的最终位置，而是沿着上位机生成的轨迹逐步运动。

适合：

- 机械臂多关节同步。
- 机器人行走和跳跃。
- 机械腿落地缓冲。
- 动力学控制。
- 高速轨迹跟踪。
- 需要改变刚度的任务。

---

#####  MIT 的第六个好处：可以在同一种通信格式中改变控制行为

MIT 的五个参数不同组合，可以得到不同效果：

| 参数组合 | 控制效果 |
|---|---|
| `KP>0、KD>0、V=0、Tff=0` | 位置保持 |
| `KP较小、KD适当` | 柔顺位置控制 |
| `KP较大、KD适当` | 刚性位置控制 |
| `KP=0、KD>0、V≠0` | 速度控制 |
| `KP=0、KD=0、Tff≠0` | 直接转矩控制 |
| `KP>0、KD>0、Tff≠0` | 位置控制加转矩补偿 |
| 动态改变 KP/KD | 可变刚度、可变阻尼控制 |

所以 MIT 的最大优势是：

> 不需要切换电机内部模式，就可以通过改变五个参数实现多种控制行为。

---

#####  MIT 的不足

######  1. 调参更困难

KP 太小：

- 电机位置保持软。
- 跟踪误差大。

KP 太大：

- 突然冲击。
- 振动。
- 啸叫。
- 过流。

KD 太小：

- 压不住振荡。
- 容易冲过目标。

KD 太大：

- 反应迟钝。
- 运动阻力大。
- 速度噪声可能转化为转矩抖动。

######  2. 前馈转矩不是转矩上限

这是 MIT 与 PVT 非常重要的区别。

例如：

```text
t_ff = 0
```

不代表最终转矩为零，因为还有：

```text
KP × 位置误差
KD × 速度误差
```

假设：

```text
目标位置 = 1 rad
实际位置 = 0 rad
KP = 10
KD = 0
t_ff = 0
```

则：
$$
\tau_{\rm cmd}=10\times(1-0)=10\ {\rm N\cdot m}
$$

虽然 `t_ff=0`，仍然可能产生很大转矩。

因此 MIT 如果需要限制最大力量，应当：

- 在上位机中限制最终转矩命令。
- 配置驱动器电流限制。
- 限制目标位置跳变。
- 合理设置 KP、KD。
- 设置过流和通讯超时保护。

######  3. 更依赖上位机

高性能 MIT 控制通常要求上位机稳定地发送：

```text
位置、速度、KP、KD、前馈转矩
```

如果发送周期抖动、轨迹不连续或突然中断，电机表现可能发生变化。因此必须配合通信超时保护。

---

####  四、相同任务下 PVT 和 MIT 的区别

#####  场景一：机械臂移动到 30°

######  使用 PVT

```text
P = 0.524 rad
V = 0.5 rad/s
T = 20%电流上限
```

含义：

```text
去30°
速度不要超过0.5 rad/s
电流不要超过最大值的20%
```

优点：

- 设置简单。
- 有明确速度上限。
- 有明确电流上限。
- 驱动器内部完成位置控制。
- 比较适合普通柔和定位。

######  使用 MIT

可能设置：

```text
p_des = 0.524 rad
v_des = 0
KP = 某个值
KD = 某个值
t_ff = 重力补偿
```

MIT 更关心：

```text
偏离目标多少时，应该产生多少恢复转矩？
运动多快时，应该产生多少制动转矩？
是否需要额外支撑重力？
```

优点：

- 可以控制关节软硬。
- 可以控制阻尼。
- 可以动态改变刚度。
- 可以增加重力补偿。
- 适合高级机器人控制。

如果只是普通定位，PVT 更省事；如果需要控制关节的动态感觉，MIT 更合适。

---

#####  场景二：机械臂碰到障碍物

假设电机距离目标还差：

```text
0.1 rad
```

######  PVT

如果电流限制为 20%：

```text
位置控制器继续增加电流
→ 达到20%
→ 被限制
```

即使目标还没有到达，最多也只能使用约 20% 电流。

这是：

> 最大用力受限。

######  MIT

如果：

```text
KP = 2
位置误差 = 0.1 rad
```

那么位置项转矩为：

```text
2 × 0.1 = 0.2 N·m
```

如果障碍物把电机推得更远，误差变成 `0.2 rad`：

```text
2 × 0.2 = 0.4 N·m
```

误差越大，恢复转矩越大，像弹簧一样。

这是：

> 力量随位移逐渐增加。

所以两者的接触感觉不同：

- PVT：内部控制器努力定位，但输出被最大电流截住。
- MIT：可以设计成软弹簧，推得越远，恢复力越大。

---

#####  场景三：用手推动机械臂

######  MIT 低 KP

例如：

```text
KP较小
KD适当
```

用手推动关节时：

- 刚偏离一点，只产生一点恢复力。
- 偏离越多，恢复力逐渐增大。
- 松手后柔和返回目标。

感觉类似真正的弹簧和减震器。

######  PVT 低电流上限

用手推动时：

- 内部位置环仍然想严格回到目标。
- 可能很快达到电流上限。
- 达到上限后，无法再增加力量。

感觉更像：

```text
一个努力保持位置、但力量有限的伺服机构
```

而不是严格意义上的软弹簧。

因此人机交互、拖动示教、机械腿落地等需要“弹性手感”的任务，MIT 通常更合适。

---

####  五、怎样选择

#####  选择 PVT，如果你的需求是

```text
去一个位置
运动不能太快
最大用力必须受到限制
不想自己详细调KP/KD
```

典型场景：

- 夹爪闭合。
- 推杆压紧。
- 普通机械臂柔和定位。
- 缓慢接近工件。
- 带电流限制的点到点运动。
- 简单软限位。

#####  选择 MIT，如果你的需求是

```text
需要调节关节软硬
需要调节阻尼
需要直接控制转矩
需要重力或动力学补偿
需要高性能实时轨迹
需要上位机完整控制运动特性
```

典型场景：

- 机器人关节阻抗控制。
- 机械臂拖动示教。
- 机械腿行走和落地。
- 直接转矩控制。
- 重力补偿。
- 多关节高速同步轨迹。
- 可变刚度控制。

一句笔记版：

```text
PVT：
去哪里、别太快、别太用力。
优点是简单，有速度上限和电流上限。

MIT：
像多硬的弹簧、像多强的减震器、额外推多少转矩。
优点是灵活，可以控制刚度、阻尼和前馈转矩。
```

## 结尾

[^1]: “闭环工作状态”是指：驱动器持续读取编码器反馈，把电机的实际状态与目标指令比较，并实时调节电流/力矩来减小误差。
