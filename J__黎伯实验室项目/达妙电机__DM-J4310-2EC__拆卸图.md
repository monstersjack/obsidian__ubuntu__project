## 相关知识点

### 定子和转子
“转子”就是电机里面会转动的部分；相对地，“定子”是固定不动的部分。
这台DM-J104229-2EC里同时存在电机转子、减速器输出端和编码器转子

####  1. 电机的转子和定子

| 名称     | 是否转动 | 主要组成           | 作用                 |
| ------ | ---- | -------------- | ------------------ |
| 定子     | 不转   | 定子铁芯、铜线绕组、固定外壳 | 通电后产生==旋转磁场==      |
| 电机转子   | 转动   | 永磁体、转子铁芯、中空轴   | 被定子磁场==推动==，产生机械旋转 |
| 输出盘    | 转动   | 减速器输出轴、外部安装法兰  | 把减速后的大扭矩传递给机械臂     |
| 黑色散热外壳 | 不转   | 铝合金外壳、散热鳍片     | 固定定子并散热            |

工作过程是：

```text
定子线圈通电
    ↓ 产生旋转磁场
电机转子高速旋转
    ↓
22:1减速器
    ↓
输出盘低速、大扭矩旋转
```

####  2. 22减速比是什么意思

减速比为22，简单理解就是：

```text
电机转子转22圈
输出盘大约转1圈
```

对应关系大约为：

| 项目 | 经过减速器后的变化 |
|---|---|
| 转速 | 降低到约1/22 |
| 转矩 | 理论上放大约22倍，实际还要乘减速器效率 |
| 位置分辨率 | 输出端控制精度提高 |
| 反射惯量 | 发生平方关系变化，需要控制器考虑 |

####  3. 双编码器是什么意思

这类一体化关节通常有两个位置测量位置：

| 编码器 | 测量对象 | 主要用途 |
|---|---|---|
| 电机侧编码器 | 测量高速电机转子的角度 | 给FOC电流控制提供转子电角度，让电机正确换相 |
| 输出侧编码器 | 测量减速器输出盘的角度 | 获得关节真实位置，提高输出端定位精度 |

两个编码器的关系可以理解为：

```text
电机侧编码器
     ↓ 测高速转子角度
电机转子 → 减速器 → 输出盘
                       ↑
                 输出侧编码器
                 测真实输出角度
```

双编码器可以帮助控制器：

- 知道电机内部==转子转到哪里==。
- 知道外部==输出盘实际转到哪里==。
- 检查减速器误差、回差和弹性变形。
- 改善输出端定位精度。
- 在算法支持时，根据输入、输出角度差估计负载或扭转变形。


####  4. “电感编码器的转子”是什么

视频中提到的应该是电感式编码器。它也分固定部分和转动部分：

| 部分 | 是否转动 | 作用 |
|---|---|---|
| 编码器PCB、线圈和芯片 | 通常固定 | 发射高频信号，检测电磁耦合变化 |
| 金属感应环/目标盘 | 随轴转动 | 改变线圈之间的耦合关系 |
| 中心轴或输出盘 | 转动 | 带动金属感应环一起旋转 |

因此，在编码器里也会把随轴旋转的金属目标盘称为“编码器转子”或“感应转子”。

它与电机转子的区别是：

- 电机转子负责产生机械动力。
- 编码器转子只负责让传感器检测角度，本身不产生动力。

####  5. 内圈和外圈可能是什么

你描述的编码器PCB有内外两圈感应线圈。它们可能分别承担：

- 内圈：检测中心高速轴或提供精细角度信号。
- 外圈：检测外侧输出盘或提供另一组角度信号。
- 两圈共同形成粗测量和精测量，用于计算绝对角度。
- 一圈用于激励，另一圈用于接收感应信号。

## 电机电路板


DM-MC-Board02 是一块“STM32H723 主控制器 + 电机配电 + CAN/RS485/传感器接口板”，不是电机内部的功率驱动板。板上几乎没有拨码开关，关键设置主要是：


####  一、最重要的电源设置

| 功能         | 控制/参数          | 实际作用                                                |     |
| ---------- | -------------- | --------------------------------------------------- | --- |
| 主电源输入      | `12～24V`       | 给控制板和电机输出供电，带防反接、缓启动                                |     |
| 电机输出1      | `PC14=1`       | 接通OUT1功率电源，配合CAN1，每路标称持续5A                          |     |
| 电机输出2      | `PC13=1`       | 接通OUT2功率电源，配合CAN2，每路标称持续5A                          |     |
| 外设5V       | `PC15=1`       | 输出5V，==供PWM、UART7/UART10（串口模块)和扩展接口使用，==总共2A，不是每路2A |     |
| USB Type-C | 5V逻辑供电         | 可以给MCU和CAN收发器供电，但不能给电机提供12～24V功率                    |     |
| 电压检测       | `PC4/ADC1_CH4` | 通过板载分压检测主输入电压                                       |     |

```text
DM-MC02开发板
├── OUT1：接第一台外部电机 → PC14控制电源 → CAN1发送命令
└── OUT2：接第二台外部电机 → PC13控制电源 → CAN2发送命令
```

| 开发板接口 | 我之前的简称 | 对应控制 | CAN通道 | 可以连接什么 |
|---|---|---|---|---|
| OUT1 | 电机1 | `PC14`控制供电 | CAN1 | 一台DM-J4310或其他兼容CAN电机 |
| OUT2 | 电机2 | `PC13`控制供电 | CAN2 | 另一台DM-J4310或其他兼容CAN电机 |

两路电机口XT30(2+2)线序是：

| 触点 | 功能 |
|---|---|
| 1 | VCC，受PC13/PC14控制 |
| 2 | GND |
| 3 | CAN_L |
| 4 | CAN_H |

####  二、CAN部分——控制达妙电机最重要

| 通道   | STM32引脚             | 外部位置            |
| ---- | ------------------- | --------------- |
| CAN1 | RX=`PD0`，TX=`PD1`   | CAN1独立口、OUT1电机口 |
| CAN2 | RX=`PB5`，TX=`PB6`   | CAN2独立口、OUT2电机口 |
| CAN3 | RX=`PD12`，TX=`PD13` | CAN3接口、24针扩展口   |

CAN外围元件的作用：

- CAN收发器：把STM32的3.3V TX/RX信号转换成差分CAN_H/CAN_L。具体型号没有标注，

####  三、其他通信接口

| 接口 | 引脚/设置 | 用途 |
|---|---|---|
| RS485/USART3 | TX=`PD8`、RX=`PD9`、DE=`PB14` | 半双工RS485，最高10Mbps |
| RS485/USART2 | TX=`PD5`、RX=`PD6`、DE=`PD4` | 半双工RS485，发送前拉高DE，发送完切回接收 |
| USART1 | TX=`PA9`、RX=`PA10` | 普通3.3V TTL串口 |
| UART7 | TX=`PE8`、RX=`PE7` | 接传感器，接口5V受PC15控制 |
| UART10 | TX=`PE3`、RX=`PE2` | 接传感器，接口5V受PC15控制 |
| SBUS | RX=`PD2` | 反相TTL，100000 baud、8E2 |
| USB FS | D-=`PA11`、D+=`PA12` | USB设备或虚拟串口等，取决于固件 |
| SWD | PA14/PA13 | SWCLK/SWDIO，用ST-Link或J-Link下载调试 |

所有UART、SPI、I²C、PWM信号应按3.3V逻辑使用。接口旁边的5V只是供电，不代表信号允许输入5V。


####  四、主控、存储和传感器

| 元件            | 用途           | 关键点                                       |
| ------------- | ------------ | ----------------------------------------- |
| STM32H723VGT6 | 整板主控制器       | Cortex-M7、550MHz、1MB内部Flash、564KB RAM     |
| 24MHz晶振       | MCU时钟基准      | 同时可由PA8给摄像头输出24MHz                        |
| W25Q64JV      | 外部QSPI Flash | 64Mbit，即8MB，可保存参数、日志、图片                   |
| ==BMI088==    | ==六轴IMU==    | 三轴加速度计+三轴陀螺仪，适合机器人振动环境                    |
| IMU加热电路       | 稳定IMU温度      | `PB1/TIM3_CH4` PWM控制，必须配合温度反馈，不能长期100%占空比 |
| WS2812        | RGB状态灯       | `PA7`控制                                   |
| 无源蜂鸣器         | 声音提示         | `PB15/TIM12_CH2`，需要PWM，典型4kHz             |
| 用户按键          | 用户输入         | `PA15`，通常低电平有效                            |
| RESET键        | MCU复位        | 直接连接MCU_RST                               |

BMI088接口为：

- SCK=`PB13`
- MOSI=`PC1`
- MISO=`PC2`
- 加速度计CS=`PC0`
- 陀螺仪CS=`PC3`
- 中断=`PE10/PE12`


####  五、PWM、LCD、摄像头和扩展口

四路PWM：

- `PA0/TIM2_CH1`
- `PA2/TIM2_CH3`
- `PE9/TIM1_CH1`
- `PE13/TIM1_CH3`

PWM信号为3.3V，旁边的5V电源由PC15控制，四路及其他外设共享2A。

LCD接口支持1.69英寸240×280屏，主要信号是：

- SPI1：`PE15、PB3、PB4、PD7`
- I²C2：`PB10、PB11`
- GPIO：`PD10`
- KEY/ADC：`PA5`
