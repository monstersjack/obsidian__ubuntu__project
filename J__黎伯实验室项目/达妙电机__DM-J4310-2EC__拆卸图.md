## 相关知识点

### 定子和转子
“转子”就是电机里面会转动的部分；相对地，“定子”是固定不动的部分。
这台DM-J104229-2EC里同时存在电机转子、减速器输出端和编码器转子

####  1. 电机的转子和定子

| 名称     | 是否转动 | 主要组成           | 作用                 |
| ------ | ---- | -------------- | ------------------ |
| 定子     | 不转   | 定子铁芯、铜线绕组、固定外壳 | 通电后产生==旋转磁场==      |
| 电机转子   | 转动   | 永磁体、转子铁芯、中空轴   | 被定子磁场==推动==，产生机械旋转 |
| 输出盘    | 转动   | 减速器输出轴、外部安装法兰  | 把减速后的大扭矩传递给机械臂     |
| 黑色散热外壳 | 不转   | 铝合金外壳、散热鳍片     | 固定定子并散热            |

工作过程是：

```text
定子线圈通电
    ↓ 产生旋转磁场
电机转子高速旋转
    ↓
22:1减速器
    ↓
输出盘低速、大扭矩旋转
```

####  2. 22减速比是什么意思

减速比为22，简单理解就是：

```text
电机转子转22圈
输出盘大约转1圈
```

对应关系大约为：

| 项目 | 经过减速器后的变化 |
|---|---|
| 转速 | 降低到约1/22 |
| 转矩 | 理论上放大约22倍，实际还要乘减速器效率 |
| 位置分辨率 | 输出端控制精度提高 |
| 反射惯量 | 发生平方关系变化，需要控制器考虑 |

####  3. 双编码器是什么意思

这类一体化关节通常有两个位置测量位置：

| 编码器    | 测量对象        | 主要用途                    |
| ------ | ----------- | ----------------------- |
| 电机侧编码器 | 测量高速电机转子的角度 | 给FOC电流控制提供转子电角度，让电机正确换相 |
| 输出侧编码器 | 测量减速器输出盘的角度 | 获得关节真实位置，提高输出端定位精度      |

两个编码器的关系可以理解为：

```text
电机侧编码器
     ↓ 测高速转子角度
电机转子 → 减速器 → 输出盘
                       ↑
                 输出侧编码器
                 测真实输出角度
```

双编码器可以帮助控制器：

- 知道电机内部==转子转到哪里==。
- 知道外部==输出盘实际转到哪里==。
- 检查减速器误差、回差和弹性变形。
- 改善输出端定位精度。
- 在算法支持时，根据输入、输出角度差估计负载或扭转变形。


####  4. “电感编码器的转子”是什么

视频中提到的应该是电感式编码器。它也分固定部分和转动部分：

| 部分 | 是否转动 | 作用 |
|---|---|---|
| 编码器PCB、线圈和芯片 | 通常固定 | 发射高频信号，检测电磁耦合变化 |
| 金属感应环/目标盘 | 随轴转动 | 改变线圈之间的耦合关系 |
| 中心轴或输出盘 | 转动 | 带动金属感应环一起旋转 |

因此，在编码器里也会把随轴旋转的金属目标盘称为“编码器转子”或“感应转子”。

它与电机转子的区别是：

- 电机转子负责产生机械动力。
- 编码器转子只负责让传感器检测角度，本身不产生动力。

####  5. 内圈和外圈可能是什么

你描述的编码器PCB有内外两圈感应线圈。它们可能分别承担：

- 内圈：检测中心高速轴或提供精细角度信号。
- 外圈：检测外侧输出盘或提供另一组角度信号。
- 两圈共同形成粗测量和精测量，用于计算绝对角度。
- 一圈用于激励，另一圈用于接收感应信号。

| 输出轴编码器  | 减速器输出端、输出法兰或输出轴附近，通常可以做成独立小板 | 减速器之后==的真实输==出轴 | 获得真实关节角度；上电后直接知道输出轴单圈绝对位置；补偿减速器回差和传动误差 | 输出轴磁铁随输出法兰旋转，固定磁传感器直接测量输出轴0～360°角度      | FOC可能仍能工作，但输出位置错误、位置控制异常或出现输出轴校准错误 |
| 电机侧折算位置 | 不是第三个编码器，是软件计算量              | 电机编码器角度÷减速比     | 估算输出轴位置，用于与直接输出角度比较                    | 根据减速比把转子累计角度换算到输出端                      | 无法完全反映齿轮回差、弹性变形和实际输出误差             |

####  六、内部四线小板是什么

如果你看到的小板：

- 位于减速器输出端；
- 靠近输出轴或输出法兰；
- 小板中心附近面对一块随输出轴转动的磁铁；
- 通过`5V、S1、S2、GND`四根线连接主驱动板；

那么它高度可能就是输出轴磁编码器板。

| 线名 | 可以确认或合理推断的作用 |
|---|---|
| 5V | 编码器板供电 |
| GND | 电源地和信号参考地 |
| S1 | 编码器信号线1 |
| S2 | 编码器信号线2 |

仅根据`S1/S2`不能确定具体协议。它们可能是时钟/数据、两路编码器信号或者厂家自定义接口。官方用户手册没有公开内部原理图，因此不能把它们直接认定为UART的TX/RX，也不能套用DM‑MC02开发板的P13/P14定义。


#### `NTC` 绕组温度检测
`NTC` 绕组温度检测线主要检测的是：**电机定子内部铜线绕组附近的温度**。

```text
U、V、W三相电流
       ↓
流过定子铜线绕组
       ↓
绕组产生热量
       ↓
埋在绕组附近的NTC检测温度
       ↓
驱动器计算温度并进行过温保护
```

DM-J4310 的 CAN 反馈里有两种温度：

| 参数 | 实际含义 |
|---|---|
| `T_MOS` | 驱动板上 MOSFET 的温度 |
| `T_Rotor` | 说明书解释为“电机内部线圈温度”，通常来自绕组附近的 NTC |

特别注意：虽然字段叫 `T_Rotor`，但官方说明书明确解释为**电机内部线圈温度**，不要理解成转子永磁体的真实温度。

NTC 的工作原理是：

- ==温度升高 → 电阻下降。==
- 驱动板通过很小的检测电流测量其电阻。
- MCU 将电阻换算成摄氏温度。
- 温度超过设定值后，电机会报“线圈过温”并失能。

由于 NTC 只测安装位置，而且热量传递需要时间，绕组真正的局部热点可能比显示温度更高。DM-J4310 说明书建议电机过温保护值不要超过约 `100℃`。这条线属于弱信号检测线，**不能接24V、三相U/V/W、CANH或CANL**。



### 减速器

行星减速器本身不是电机，也不产生动力。它接收电机转子的高速旋转，把它转换成输出端的==低速、大转矩==旋转。

以 DM-J4310 的 `10:1` 为例：

```text
电机转子转10圈
        ↓
减速器输出端转约1圈
```

####  一、主要作用

| 作用      | 简单理解                     |
| ------- | ------------------------ |
| 降低转速    | 电机转得很快，经过减速器后输出变慢        |
| 放大转矩    | 输出端推、拉、抬重物的能力增强          |
| 提高控制分辨率 | 电机转动10°，输出端只转约1°，更容易精细控制 |
| 承受负载    | 多个行星齿轮共同传力，可以分担较大的负载     |
| 保持同轴    | 输入轴和输出轴位于同一中心，结构紧凑       |


####  二、行星减速器有哪些零件

常见行星减速器包含四个主要部分：

| 零件  |  是否转动 | 作用                   |
| --- | ----: | -------------------- |
| 太阳轮 |    转动 | 位于中心，通常连接电机转子，是动力输入端 |
| 行星轮 | 自转并公转 | 同时与太阳轮和齿圈啮合，传递动力     |
| 内齿圈 |  通常固定 | 固定在外壳内部，限制行星轮的运动轨迹   |
| 行星架 |    转动 | 安装所有行星轮，通常作为减速后的输出端  |

结构关系可以简化为：

```text
电机转子
   ↓
太阳轮高速旋转
   ↓
多个行星轮一边自转、一边绕太阳轮公转
   ↓
带动行星架缓慢旋转
   ↓
输出盘低速、大转矩旋转
```

之所以叫“行星”，是因为行星轮的运动类似行星：

- 行星轮绕自己的轴旋转，称为“自转”。
- 行星轮同时绕中心太阳轮运动，称为“公转”。

####  三、它为什么能够减速

常见工作方式是：

```text
太阳轮：输入
内齿圈：固定
行星架：输出
```

电机带动太阳轮高速旋转。行星轮不能直接自由离开，因为外侧还与固定的内齿圈啮合，所以它们只能沿着==内齿圈慢慢“爬行”。==

行星轮的公转速度比太阳轮慢，因此连接所有行星轮的行星架也缓慢转动，最终实现减速。

```text
太阳轮快速转动
     ↓
行星轮沿固定齿圈缓慢移动
     ↓
行星架缓慢转动
```

同时，太阳轮输入的力通过多个行星轮共同传递给行星架，所以输出端能够得到更大的转矩。

####  四、多个行星轮有什么作用

一般会使用3个或更多行星轮，而不是只使用一个。

主要原因是：

- 多个齿轮共同承担转矩。
- 受力分布更均匀。
- 中心太阳轮不容易被推向一侧。
- 能在较小体积内传递较大转矩。
- 输入轴和输出轴可以保持同轴。

不过，这并不表示行星轮数量越多一定越好。齿轮数量增加后，加工、装配和载荷均分会更加困难。

####  六、10:1对控制有什么影响

假设减速比为10：

|      电机转子侧 |           输出端 |
| ---------: | ------------: |
|       转10圈 |          约转1圈 |
| 转速1000 rpm |      约100 rpm |
|      转动10° |         约转动1° |
|  转矩0.4 N·m | 理想约4 N·m，实际更低 |

控制器必须知道减速比，才能把电机侧编码器数据换算成输出端位置：

```text
输出位置 ≈ 电机转子位置 ÷ 10
输出速度 ≈ 电机转子速度 ÷ 10
```

DM-J4310 还有输出侧编码器，可以直接测量输出盘实际角度，用来补偿齿轮间隙和传动误差。

需要严谨说明：DM-J4310 官方参数表明确写了内置减速器为 `10:1`，但参数表没有直接注明其内部一定属于行星式。以上是按照常见的“太阳轮输入、齿圈固定、行星架输出”的行星减速结构解释。

## 电机电路板


DM-MC-Board02 是一块“STM32H723 主控制器 + 电机配电 + CAN/RS485/传感器接口板”，不是电机内部的功率驱动板。板上几乎没有拨码开关，关键设置主要是：


####  一、最重要的电源设置

| 功能         | 控制/参数          | 实际作用                                                |     |
| ---------- | -------------- | --------------------------------------------------- | --- |
| 主电源输入      | `12～24V`       | 给控制板和电机输出供电，带防反接、缓启动                                |     |
| 电机输出1      | `PC14=1`       | 接通OUT1功率电源，配合CAN1，每路标称持续5A                          |     |
| 电机输出2      | `PC13=1`       | 接通OUT2功率电源，配合CAN2，每路标称持续5A                          |     |
| 外设5V       | `PC15=1`       | 输出5V，==供PWM、UART7/UART10（串口模块)和扩展接口使用，==总共2A，不是每路2A |     |
| USB Type-C | 5V逻辑供电         | 可以给MCU和CAN收发器供电，但不能给电机提供12～24V功率                    |     |
| 电压检测       | `PC4/ADC1_CH4` | 通过板载分压检测主输入电压                                       |     |

```text
DM-MC02开发板
├── OUT1：接第一台外部电机 → PC14控制电源 → CAN1发送命令
└── OUT2：接第二台外部电机 → PC13控制电源 → CAN2发送命令
```

| 开发板接口 | 我之前的简称 | 对应控制 | CAN通道 | 可以连接什么 |
|---|---|---|---|---|
| OUT1 | 电机1 | `PC14`控制供电 | CAN1 | 一台DM-J4310或其他兼容CAN电机 |
| OUT2 | 电机2 | `PC13`控制供电 | CAN2 | 另一台DM-J4310或其他兼容CAN电机 |

两路电机口XT30(2+2)线序是：

| 触点 | 功能 |
|---|---|
| 1 | VCC，受PC13/PC14控制 |
| 2 | GND |
| 3 | CAN_L |
| 4 | CAN_H |

| 通道   | STM32引脚             | 外部位置            |

| CAN3 | RX=`PD12`，TX=`PD13` | CAN3接口、24针扩展口   |

CAN外围元件的作用：

- CAN收发器：把STM32的3.3V TX/RX信号转换成差分CAN_H/CAN_L。具体型号没有标注，

| RS485/USART3 | TX=`PD8`、RX=`PD9`、DE=`PB14` | 半双工RS485，最高10Mbps |

####  五、PWM、LCD、摄像头和扩展口
