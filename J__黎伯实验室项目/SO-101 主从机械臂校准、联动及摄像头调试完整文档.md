## 1. 当前设备对应关系

| 设备     | 作用                | 系统端口           | LeRobot配置名称      |
| ------ | ----------------- | -------------- | ---------------- |
| 从动执行臂  | Follower，被控制并执行动作 | `/dev/ttyACM1` | `so101_follower` |
| 主手控制臂  | Leader，由操作人员手动推动  | `/dev/ttyACM0` | `so101_leader`   |
| 机械臂摄像头 | 采集机械臂工作区域图像       | `/dev/video0`  | 摄像头编号 `0`        |

注意：

* `so101_follower` 和 `so101_leader` 是LeRobot的校准配置名称。
* 它们不是机械臂内部电机刷写的数字ID。
* 电机数字ID通常为1～6，每个关节的数字ID必须唯一。
* Ubuntu重启或重新插拔USB后，`ttyACM0` 和 `ttyACM1` 可能交换，因此每次操作前建议重新确认。

## 3. 验证主从机械臂串口

查看所有ACM串口：

```bash
ls -l /dev/ttyACM*
```

正常应包含：

```text
/dev/ttyACM0
/dev/ttyACM1
```

使用LeRobot识别机械臂端口：

```bash
lerobot-find-port
```

操作方法：

1. 保持主手和从动臂都连接到电脑。
2. 执行 `lerobot-find-port`。
3. 程序要求拔掉设备时，==只拔掉需要识别的机械臂==USB数据线。
4. 按回车。
5. 程序会显示刚刚被拔掉的设备端口。
6. 记录端口后重新插回USB。

如果拔掉从动臂后程序显示：

`The port of this MotorsBus is /dev/ttyACM1`

说明：

`/dev/ttyACM1 = 从动执行臂`

当前对应关系为：

```text
/dev/ttyACM1 = follower
/dev/ttyACM0 = leader
```

如果重新插拔后端口交换，直接修改命令里的实际端口。例如从动臂变成 `/dev/ttyACM0`，就把所有==从动臂命令==里的：

```text
--robot.port=/dev/ttyACM1
```

修改为：

```text
--robot.port=/dev/ttyACM0
```

## 4. 所有命令参数统一解析

| 命令或参数                         | 所属设备     | 详细含义                                                | 使用注意事项                              |
| ----------------------------- | -------- | --------------------------------------------------- | ----------------------------------- |
| `lerobot-calibrate`           | 主手或从动臂   | 启动==LeRobot校准程序==，用于连接设备、记录关节中间位置、关节最小值和最大值，并保存校准数据 | 主手和从动臂需要分别执行一次                      |
| `lerobot-teleoperate`         | 主手和从动臂   | 启动==实时遥操作程序==，读取主手关节位置并控制从动臂跟随                      | 启动前应让主手和从动臂处于相近姿态                   |
| `\`                           | Bash命令格式 | Bash续行符，表示下一行仍属于同一条命令                               | 本笔记中的可执行命令全部写成一行，因此不使用续行符           |
| `--robot.type=so101_follower` | 从动臂      | 指定被控制的机器人类型是SO-101 Follower                         | `robot` 表示实际执行动作的机械臂                |
| `--robot.port=/dev/ttyACM1`   | 从动臂      | 指定从动臂控制板对应的Linux串口                                  | 必须与实际从动臂端口一致                        |
| `--robot.id=so101_follower`   | 从动臂      | 指定从动臂的==LeRobot配置名称==，LeRobot根据该名称保存和读取校准数据         | 不是电机数字ID；校准、遥操作、采集和回放应保持相同名称        |
| `--teleop.type=so101_leader`  | 主手       | 指定遥操作设备类型是SO-101 Leader                             | `teleop` 是teleoperator的缩写，表示遥操作控制设备 |
| `--teleop.port=/dev/ttyACM0`  | 主手       | 指定主手控制板对应的Linux串口                                   | 必须与实际主手端口一致                         |
| `--teleop.id=so101_leader`    | 主手       | 指定主手的LeRobot配置名称，用于保存和读取主手校准数据                      | 校准、遥操作和数据采集时应保持相同名称                 |
| `--robot.cameras="..."`       | 摄像头      | 为从动机器人配置一个或多个摄像头                                    | 整个摄像头配置需要用双引号包围                     |
| `front`                       | 摄像头      | 给摄像头设置名称，本笔记中命名为前置摄像头                               | 后续采集数据时会使用该名称保存图像字段                 |
| `type: opencv`                | 摄像头      | 使用OpenCV驱动普通USB摄像头                                  | 适合普通USB摄像头和电脑内置摄像头                  |
| `index_or_path: 0`            | 摄像头      | 使用OpenCV编号为0的摄像头                                    | 当前通常对应 `/dev/video0`                |
| `width: 640`                  | 摄像头      | 设置图像宽度为640像素                                        | 必须是摄像头支持的分辨率                        |
| `height: 480`                 | 摄像头      | 设置图像高度为480像素                                        | 与宽度共同组成640×480分辨率                   |
| `fps: 30`                     | 摄像头      | 设置摄像头采集速度为每秒30帧                                     | 如果打不开，可以降低到15帧                      |
| `--display_data=true`         | 可视化      | 打开Rerun可视化界面，显示摄像头画面和关节状态                           | 如果缺少Rerun依赖，需要安装可视化组件               |

## 5. 校准提示中 `c` 的含义

运行校准命令后，可能出现：

```text
Press ENTER to use provided calibration file associated with the id so101_follower, or type 'c' and press ENTER to run calibration:
```

不同操作的含义如下：

| 操作                  | 含义                   | 使用场景                           |
| ------------------- | -------------------- | ------------------------------ |
| 直接按 `Enter`         | 使用该配置名称下已经保存的校准文件    | 机械臂已经成功校准，并且没有重新拆装或更换电机        |
| 输入小写 `c` 后按 `Enter` | 放弃直接使用旧校准结果，重新执行完整校准 | 第一次使用、刚刷完电机ID、更换电机、重新装配或者旧校准错误 |
| 按 `Ctrl+C`          | 取消并退出校准程序            | 当前不准备继续校准                      |

`c` 可以理解为：

```text
calibrate = 执行校准
```

建议统一输入小写：

```text
c
```

## 6. 校准时的正确操作方法

输入 `c` 后，程序首先提示：

```text
Move the robot to the middle of its range of motion and press ENTER.
```

此时：

1. ==把机械臂所有关节放到大致中间位置。==
2. 底座朝向正前方。
3. 大臂保持中间高度。
4. 肘关节保持中等弯曲。
5. 手腕保持中间位置。
6. 夹爪保持半开。
7. 摆好后按回车。

随后程序提示：

```text
Recording positions. Press ENTER to stop...
```

此时不要立即按回车，需要依次活动关节：

| 关节名称            | 实际位置  | 操作要求            |
| --------------- | ----- | --------------- |
| `shoulder_pan`  | 底座    | 缓慢经过左右两侧的完整安全行程 |
| `shoulder_lift` | 肩部    | 缓慢经过最低和最高安全位置   |
| `elbow_flex`    | 肘部    | 缓慢完全弯曲和展开       |
| `wrist_flex`    | 手腕俯仰  | 缓慢向上和向下活动       |
| `gripper`       | 夹爪或手柄 | 完全打开并完全闭合       |

如果程序显示：

```text
Move all joints except 'wrist_roll'
```

表示本次范围记录不需要活动 `wrist_roll`。

正常数值类似：

```text
NAME            |    MIN |    POS |    MAX
shoulder_pan    |    850 |   2047 |   3260
shoulder_lift   |    920 |   2100 |   3100
elbow_flex      |    760 |   1900 |   3310
wrist_flex      |   1030 |   2150 |   3160
gripper         |   1580 |   2050 |   2560
```

具体数值不需要与示例相同，但每个关节必须满足：

```text
MIN 和 MAX 不相同
```

所有关节完成完整安全行程后，再按回车结束记录。

## 7. 主从臂双臂校准及遥操作完整测试

这一部分包含：

1. 校准从动执行臂；
2. 校准主手控制臂；
3. 不带摄像头进行主从遥操作。

### 7.1 校准从动执行臂

当前从动执行臂是：

```text
/dev/ttyACM1
```

执行以下一行命令：

```bash
lerobot-calibrate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=so101_follower
```

出现校准文件提示后，需要重新校准就输入：

```text
c
```

然后按照第6节的方法完成中间位置和关节范围记录。

成功时应满足：

* 显示 `so101_follower SOFollower connected`；
* 所有关节数值能够正常变化；
* 每个关节的 `MIN` 和 `MAX` 不同；
* 没有出现 `Traceback`；
* 程序最后正常断开从动臂。

### 7.2 校准主手控制臂

当前主手控制臂是：

```text
/dev/ttyACM0
```

执行以下一行命令：

```bash
lerobot-calibrate --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=so101_leader
```

需要重新校准时输入：

```text
c
```

然后：

1. 把主手放在中间姿态；
2. 按回车；
3. 出现记录提示后依次活动关节；
4. 主手夹爪手柄需要完全打开和闭合；
5. 完成后按回车保存。

成功时应满足：

* 显示 `so101_leader SOLeader connected`；
* 主手关节数值能够正常变化；
* 没有出现 `Traceback`；
* 程序最后正常断开主手。

### 7.3 启动前安全检查

进行主从遥操作前：

1. 把主手和从动臂摆成大致相同的姿态。
2. 清除机械臂周围的障碍物。
3. 不要让人员站在机械臂运动范围内。
4. 第一次测试只进行小幅度、缓慢操作。
5. 准备随时按 `Ctrl+C`。
6. 如果从动臂突然快速运动，立即停止程序或关闭机械臂电源。

### 7.4 不带摄像头进行主从遥操作

执行以下一行命令：

```bash
lerobot-teleoperate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=so101_follower --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=so101_leader
```

成功连接时通常会显示类似：

```text
INFO ... so101_follower SOFollower connected.
INFO ... so101_leader SOLeader connected.
```

判断主从遥操作成功：

* Follower显示 `connected`；
* Leader显示 `connected`；
* 没有出现 `Traceback`；
* 移动主手时从动臂同步运动；
* 各关节运动方向正确；
* 主手夹爪开合时从动夹爪同步开合；
* 机械臂没有明显跳动或剧烈抖动。

结束遥操作：

```text
Ctrl+C
```

## 8. 摄像头检查与调试

### 8.1 查看全部摄像头

执行以下一行命令：

```bash
v4l2-ctl --list-devices
```

你此前确认的设备大致为：

```text
HD Webcam
/dev/video0
/dev/video1

Integrated_Webcam_HD
/dev/video2
/dev/video3
```

其中：

```text
/dev/video0 = 机械臂外置摄像头
/dev/video2 = 电脑内置摄像头
```

### 8.2 查看机械臂摄像头支持的格式

```bash
v4l2-ctl --device=/dev/video0 --list-formats-ext
```

当前机械臂摄像头已确认支持：

```text
MJPG
640×480
30 FPS
```

### 8.3 使用LeRobot检测摄像头

优先执行：

```bash
lerobot-find-cameras opencv
```

如果当前版本不接受 `opencv` 参数，可以执行：

```bash
lerobot-find-cameras
```

正常输出类似：

```text
--- Detected Cameras ---
Camera #0:
  Name: OpenCV Camera @ 0
  Type: OpenCV
  Id: 0
```

这里的：

```text
Id: 0
```

通常对应：

```text
/dev/video0
```

### 8.4 单独预览摄像头

```bash
ffplay -f v4l2 -input_format mjpeg -video_size 640x480 -framerate 30 /dev/video0
```

成功时会弹出实时画面。

关闭摄像头预览：

```text
按 q
```

或者：

```text
Ctrl+C
```

在启动LeRobot带摄像头遥操作前，必须关闭ffplay，否则摄像头可能被占用。

### 8.5 拍摄一张测试照片

```bash
ffmpeg -f v4l2 -input_format mjpeg -video_size 640x480 -framerate 30 -i /dev/video0 -frames:v 1 camera_test.jpg
```

检查照片：

```bash
ls -lh camera_test.jpg
```

打开照片：

```bash
xdg-open camera_test.jpg
```

## 9. 机械臂加摄像头完整遥操作

确认以下内容都正常后再启动：

* 从动臂已经校准成功；
* 主手已经校准成功；
* 不带摄像头的主从联动正常；
* `/dev/video0` 可以正常显示画面；
* ffplay和其他摄像头软件已经关闭。

### 9.1 推荐完整命令

以下命令全部写在一行：

```bash
lerobot-teleoperate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=so101_follower --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=so101_leader --display_data=true
```

成功后应满足：

* Follower显示 `connected`；
* Leader显示 `connected`；
* 主手能够控制从动臂；
* Rerun可视化窗口正常打开；
* 可以看到名为 `front` 的摄像头画面；
* 摄像头画面持续更新；
* 终端没有出现 `Traceback`。

### 9.2 摄像头30帧无法打开时

将帧率降低为15：

```bash
lerobot-teleoperate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=so101_follower --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 15}}" --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=so101_leader --display_data=true
```

### 9.3 使用设备路径的备用写法

如果当前版本支持直接填写Linux摄像头路径，可以尝试：

```bash
lerobot-teleoperate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=so101_follower --robot.cameras="{front: {type: opencv, index_or_path: /dev/video0, width: 640, height: 480, fps: 30}}" --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=so101_leader --display_data=true
```

建议优先使用：

```text
index_or_path: 0
```

## 10. 常见错误处理

### 10.1 所有关节一直显示2047

错误表现：

```text
shoulder_pan | 2047 | 2047 | 2047
shoulder_lift | 2047 | 2047 | 2047
elbow_flex | 2047 | 2047 | 2047
wrist_flex | 2047 | 2047 | 2047
gripper | 2047 | 2047 | 2047
```

随后出现：

```text
ValueError: Some motors have the same min and max values
```

先确认出现：

```text
Recording positions. Press ENTER to stop...
```

以后确实逐个活动了关节，而不是立即按回车。

如果活动后仍然全部为2047，需要检查：

* 是否连接了正确的机械臂端口；
* 机械臂是否正常供电；
* 电机数字ID是否正确；
* 是否有多个电机使用相同ID；
* 电机三针线是否松动；
* 控制板和电机波特率是否一致；
* USB数据线是否正常；
* 是否错误连接了另一只机械臂。

### 10.2 串口权限错误

如果出现：

```text
Permission denied
```

执行：

```bash
sudo usermod -aG dialout jack
```

然后注销Ubuntu账户并重新登录。

检查用户组：

```bash
groups jack
```

输出中应包含：

```text
dialout
```

### 10.3 摄像头被占用

查看占用程序：

```bash
fuser /dev/video0
```

关闭可能占用摄像头的软件：

* ffplay；
* 浏览器；
* 视频会议软件；
* Cheese；
* 其他OpenCV程序；
* 上一次没有正常结束的LeRobot程序。

### 10.4 缺少Rerun可视化组件

在LeRobot目录执行：

```bash
cd ~/lerobot
```

```bash
pip install -e ".[feetech,viz]"
```

安装完成后重新运行带摄像头遥操作命令。
