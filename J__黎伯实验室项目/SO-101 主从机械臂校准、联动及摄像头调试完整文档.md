## 1. 当前设备对应关系

本笔记严格按照以下设备关系编写：

```text
/dev/ttyACM1 = 从动执行臂 follower
/dev/ttyACM0 = 主手控制臂 leader
/dev/video0   = 机械臂外置摄像头
```

对应的LeRobot校准配置名称：

```text
从动臂配置名称：so101_follower
主手配置名称：so101_leader
```

注意：

```text
so101_follower 和 so101_leader 是校准配置名称，
不是机械臂内部电机刷写的数字ID。
```

机械臂内部电机通常使用数字ID：

```text
1 = shoulder_pan
2 = shoulder_lift
3 = elbow_flex
4 = wrist_flex
5 = wrist_roll
6 = gripper
```

# 2. 每次操作前进入LeRobot环境

打开Ubuntu终端，执行：

```bash
conda activate lerobot
cd ~/lerobot
```

进入成功后，终端前面通常会显示：

```text
(lerobot) jack@jack:~/lerobot
```

检查LeRobot命令是否存在：

```bash
which lerobot-calibrate
```

正常应显示类似：

```text
/home/jack/miniforge3/envs/lerobot/bin/lerobot-calibrate
```

检查遥操作命令：

```bash
which lerobot-teleoperate
```

正常应显示类似：

```text
/home/jack/miniforge3/envs/lerobot/bin/lerobot-teleoperate
```

查看帮助：

```bash
lerobot-calibrate --help
```

```bash
lerobot-teleoperate --help
```

如果这两个命令都能正常显示帮助信息，说明当前LeRobot环境基本正常。

# 3. 检查主手和从动臂串口

执行：

```bash
ls -l /dev/ttyACM*
```

正常应看到：

```text
/dev/ttyACM0
/dev/ttyACM1
```

可能显示类似：

```text
crw-rw---- 1 root dialout 166, 0 ... /dev/ttyACM0
crw-rw---- 1 root dialout 166, 1 ... /dev/ttyACM1
```

当前确认的对应关系是：

```text
/dev/ttyACM1 = follower 从动执行臂
/dev/ttyACM0 = leader 主手控制臂
```

## 3.1 使用LeRobot验证端口

执行：

```bash
lerobot-find-port
```

终端会显示当前发现的串口，并提示拔掉一个机械臂的USB连接。

操作流程：

1. 保持两个机械臂已经连接。
2. 执行 `lerobot-find-port`。
3. 程序提示拔掉设备时，只拔掉需要识别的机械臂USB数据线。
4. 按回车。
5. 程序会判断消失的是哪个串口。
6. 记录端口后重新插回USB。

如果拔掉从动臂后程序显示：

```text
The port of this MotorsBus is /dev/ttyACM1
```

说明：

```text
/dev/ttyACM1 = 从动执行臂
```

如果拔掉主手后程序显示：

```text
The port of this MotorsBus is /dev/ttyACM0
```

说明：

```text
/dev/ttyACM0 = 主手控制臂
```

## 3.2 重新插拔后端口可能变化

Ubuntu重新启动或重新插拔USB以后，端口可能交换。

例如可能变成：

```text
/dev/ttyACM0 = follower
/dev/ttyACM1 = leader
```

发生变化后，直接修改命令里的实际端口即可。

例如从动臂变成 `/dev/ttyACM0`，原参数：

```bash
--robot.port=/dev/ttyACM1
```

需要改为：

```bash
--robot.port=/dev/ttyACM0
```

主手变成 `/dev/ttyACM1`，原参数：

```bash
--teleop.port=/dev/ttyACM0
```

需要改为：

```bash
--teleop.port=/dev/ttyACM1
```

不要仅凭 `ttyACM0` 或 `ttyACM1` 的编号判断主从关系，每次重新插拔后都建议重新确认。

# 4. 校准从动执行臂 Follower

当前从动执行臂端口：

```text
/dev/ttyACM1
```

完整校准命令：

```bash
lerobot-calibrate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower
```

## 4.1 命令参数解析

### `lerobot-calibrate`

```text
启动LeRobot设备校准程序。
```

该命令负责：

* 连接机械臂；
* 检查已有校准文件；
* 读取关节位置；
* 记录关节中间位置；
* 记录关节最小值和最大值；
* 保存校准结果。

### 反斜杠

```bash
\
```

反斜杠是Bash续行符，表示下一行仍属于同一条命令。

注意，反斜杠后面不能再添加空格，否则可能导致命令续行失败。

也可以把整条命令写成一行：

```bash
lerobot-calibrate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=so101_follower
```

两种写法作用完全相同。

### `--robot.type=so101_follower`

```text
指定被校准的设备是SO-101从动执行臂。
```

其中：

```text
robot   = 被控制、实际执行动作的机械臂
type    = 机械臂类型
so101_follower = SO-101从动臂驱动类型
```

### `--robot.port=/dev/ttyACM1`

```text
指定从动臂控制板使用的串口。
```

这里必须和实际从动臂端口一致。

### `--robot.id=so101_follower`

```text
指定从动臂的校准配置名称。
```

LeRobot会根据这个名称保存和读取校准数据。

后续进行：

* 主从遥操作；
* 数据采集；
* 数据回放；
* 模型推理；

都应继续使用：

```bash
--robot.id=so101_follower
```

不要随意改成其他名称，否则LeRobot可能找不到原来的校准文件。

# 5. 校准提示中 `c` 的含义

运行从动臂校准命令后，可能出现：

```text
Press ENTER to use provided calibration file associated with the id so101_follower,
or type 'c' and press ENTER to run calibration:
```

这句话的意思是：

```text
直接按回车：使用已经存在的校准文件。
输入小写c并回车：重新执行完整校准。
```

## 5.1 直接按回车

输入方式：

```text
直接按 Enter
```

作用：

```text
使用 so101_follower 已经保存的校准数据，不重新校准。
```

适用于：

* 机械臂已经成功校准；
* 没有重新拆装机械臂；
* 没有更换电机；
* 没有重新刷写电机ID；
* 关节方向和跟随效果正常。

## 5.2 输入小写 `c`

输入：

```text
c
```

然后按回车。

`c` 可以理解为：

```text
calibrate = 执行校准
```

作用：

```text
不使用原来的校准结果，重新记录当前机械臂的校准数据。
```

以下情况应该输入 `c`：

* 第一次安装机械臂；
* 刚刚刷完电机ID；
* 更换过电机；
* 重新安装过关节；
* 原来的校准失败；
* 关节方向不正确；
* 从动臂不能正确跟随主手；
* 需要覆盖旧校准数据。

## 5.3 退出校准程序

如果不想继续，按：

```text
Ctrl+C
```

## 5.4 该提示还有没有其他命令

这个提示中正常使用的操作只有：

```text
直接按 Enter
输入 c 后按 Enter
按 Ctrl+C 退出
```

不要输入：

```text
y
yes
n
no
```

这些不是该提示定义的选项。

虽然部分版本输入大写 `C` 也能识别，但建议统一输入小写：

```text
c
```

# 6. 从动臂正确校准操作

输入 `c` 后，终端会显示类似：

```text
Running calibration of so101_follower SOFollower
Move so101_follower SOFollower to the middle of its range of motion and press ENTER....
```

## 6.1 摆放中间位置

将机械臂摆到所有关节的大致中间位置。

建议姿态：

* 底座朝向正前方；
* 大臂处于不上不下的中间位置；
* 肘关节保持中等弯曲；
* 手腕保持中间位置；
* 夹爪保持半开；
* 不要让任何关节停在机械限位附近。

摆好后按回车。

## 6.2 记录关节运动范围

随后出现：

```text
Move all joints except 'wrist_roll' sequentially through their entire ranges of motion.
Recording positions. Press ENTER to stop...
```

这时不要立即按回车。

依次缓慢活动以下关节：

| 终端名称            | 对应关节 | 操作            |
| --------------- | ---- | ------------- |
| `shoulder_pan`  | 底座旋转 | 缓慢转到左侧和右侧安全范围 |
| `shoulder_lift` | 肩部抬升 | 缓慢经过最低和最高安全位置 |
| `elbow_flex`    | 肘部弯曲 | 缓慢完全弯曲和展开     |
| `wrist_flex`    | 手腕俯仰 | 缓慢向上和向下活动     |
| `gripper`       | 夹爪   | 完全打开并完全闭合     |

程序明确提示：

```text
except 'wrist_roll'
```

因此本次从动臂校准时，不需要专门让 `wrist_roll` 经过完整行程。

如果你安装的LeRobot版本显示了不同提示，应以终端当时的提示为准。

## 6.3 正常数值

终端中的数值应该随着手动活动关节不断变化，例如：

```text
NAME            |    MIN |    POS |    MAX
shoulder_pan    |    850 |   2047 |   3260
shoulder_lift   |    920 |   2100 |   3100
elbow_flex      |    760 |   1900 |   3310
wrist_flex      |   1030 |   2150 |   3160
gripper         |   1580 |   2050 |   2560
```

具体数值不需要和示例相同。

成功的关键是每个关节满足：

```text
MIN 和 MAX 不相同
```

所有关节都完成完整安全行程后，再按回车停止记录。

不要用力撞击机械限位，也不要在关节明显带力时强行掰动。

## 6.4 从动臂校准成功的判断

成功时通常满足：

```text
显示 so101_follower SOFollower connected
每个关节的 MIN 和 MAX 不同
程序正常保存校准数据
程序最后正常断开机械臂
没有出现 Traceback
```

可能看到类似：

```text
INFO ... so101_follower SOFollower connected.
INFO ... Running calibration of so101_follower SOFollower
INFO ... so101_follower SOFollower disconnected.
```

不同LeRobot版本的最终保存提示可能略有差异。

# 7. 校准主手控制臂 Leader

当前主手控制臂端口：

```text
/dev/ttyACM0
```

完整命令：

```bash
lerobot-calibrate \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader
```

也可以写成一行：

```bash
lerobot-calibrate --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=so101_leader
```

## 7.1 参数解析

### `--teleop.type=so101_leader`

```text
指定校准设备为SO-101主手控制臂。
```

其中：

```text
teleop = teleoperator，遥操作控制设备
leader = 主手，由操作人员手动推动
```

### `--teleop.port=/dev/ttyACM0`

```text
指定主手控制板端口为 /dev/ttyACM0。
```

### `--teleop.id=so101_leader`

```text
指定主手校准配置名称为 so101_leader。
```

后续遥操作和采集数据时，必须继续使用相同的：

```bash
--teleop.id=so101_leader
```

## 7.2 主手校准操作

如果出现：

```text
Press ENTER to use provided calibration file associated with the id so101_leader,
or type 'c' and press ENTER to run calibration:
```

需要重新校准时输入：

```text
c
```

然后：

1. 将主手所有关节摆到大致中间位置。
2. 按回车记录中间位置。
3. 出现 `Recording positions` 后不要立即结束。
4. 依次缓慢活动终端要求的全部关节。
5. 主手夹爪手柄需要完整打开和闭合。
6. 检查每个关节的 `MIN` 和 `MAX` 是否不同。
7. 全部活动完成后再按回车保存。

成功判断：

```text
显示 so101_leader SOLeader connected
各关节数值可以正常变化
没有出现 Traceback
程序最后正常断开主手
```

# 8. 不带摄像头进行主从联动测试

建议先不加入摄像头，单独确认机械臂主从控制正常。

## 8.1 启动前安全准备

启动前完成以下操作：

1. 将主手和从动臂摆成大致相同的姿态。
2. 清理机械臂周围的工具和障碍物。
3. 不要让人员站在机械臂运动范围内。
4. 第一次测试时只小幅度、缓慢移动主手。
5. 准备随时按 `Ctrl+C`。
6. 如果机械臂突然异常运动，立即切断机械臂电源。

## 8.2 完整联动命令

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader
```

单行版本：

```bash
lerobot-teleoperate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=so101_follower --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=so101_leader
```

## 8.3 参数解析

| 参数                            | 作用                |
| ----------------------------- | ----------------- |
| `lerobot-teleoperate`         | 启动实时主从遥操作         |
| `--robot.type=so101_follower` | 指定执行动作的是SO-101从动臂 |
| `--robot.port=/dev/ttyACM1`   | 指定从动臂端口           |
| `--robot.id=so101_follower`   | 加载从动臂校准文件         |
| `--teleop.type=so101_leader`  | 指定控制设备是SO-101主手   |
| `--teleop.port=/dev/ttyACM0`  | 指定主手端口            |
| `--teleop.id=so101_leader`    | 加载主手校准文件          |

## 8.4 联动成功输出

成功连接通常会看到类似：

```text
INFO ... so101_follower SOFollower connected.
INFO ... so101_leader SOLeader connected.
```

判断联动成功：

* 终端没有出现 `Traceback`；
* Follower显示 `connected`；
* Leader显示 `connected`；
* 缓慢移动主手时，从动臂同步运动；
* 各关节运动方向正确；
* 主手夹爪开合时，从动夹爪同步开合；
* 没有明显跳动、撞限位或剧烈抖动。

结束遥操作：

```text
Ctrl+C
```

正常情况下程序会断开两个设备。

# 10. 单独测试摄像头画面

在加入机械臂联动前，先单独确认摄像头可以正常出图。

## 10.1 使用ffplay实时预览

```bash
ffplay \
  -f v4l2 \
  -input_format mjpeg \
  -video_size 640x480 \
  -framerate 30 \
  /dev/video0
```

参数含义：

| 参数                    | 含义                |
| --------------------- | ----------------- |
| `ffplay`              | 打开视频预览窗口          |
| `-f v4l2`             | 使用Linux V4L2摄像头接口 |
| `-input_format mjpeg` | 指定摄像头输出MJPEG      |
| `-video_size 640x480` | 设置分辨率             |
| `-framerate 30`       | 设置30帧每秒           |
| `/dev/video0`         | 指定机械臂摄像头          |

成功时会弹出实时画面。

退出：

```text
按 q
```

或者：

```text
Ctrl+C
```

在启动LeRobot带摄像头联动之前，必须先关闭 `ffplay`，否则摄像头可能被占用。

## 10.2 拍摄测试照片

```bash
ffmpeg \
  -f v4l2 \
  -input_format mjpeg \
  -video_size 640x480 \
  -framerate 30 \
  -i /dev/video0 \
  -frames:v 1 \
  camera_test.jpg
```

检查照片：

```bash
ls -lh camera_test.jpg
```

打开照片：

```bash
xdg-open camera_test.jpg
```

# 11. 机械臂加摄像头完整联动测试

确认以下项目都正常后再进行：

```text
从动臂校准成功
主手校准成功
不带摄像头联动正常
/dev/video0 可以正常显示画面
ffplay 已经关闭
```

## 11.1 推荐完整命令

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader \
  --display_data=true
```

## 11.2 摄像头参数解析

### `--robot.cameras`

```text
为从动机器人配置摄像头。
```

### `front`

```text
摄像头名称。
```

这里将机械臂摄像头命名为：

```text
front
```

后续采集数据时，图像数据也会按照这个名称保存。

不要在同一个数据集采集过程中随意把 `front` 改成其他名称。

### `type: opencv`

```text
使用LeRobot的OpenCV摄像头驱动。
```

适用于普通USB摄像头和电脑内置摄像头。

### `index_or_path: 0`

```text
使用编号为0的OpenCV摄像头。
```

在当前设备中一般对应：

```text
/dev/video0
```

### `width: 640`

```text
图像宽度为640像素。
```

### `height: 480`

```text
图像高度为480像素。
```

### `fps: 30`

```text
摄像头采集速度为每秒30帧。
```

### `--display_data=true`

```text
打开Rerun可视化界面。
```

正常情况下可以看到：

* 摄像头实时画面；
* 机械臂关节状态；
* 遥操作数据。

## 11.3 使用 `/dev/video0` 路径的备用命令

如果当前LeRobot版本支持直接填写设备路径，也可以尝试：

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower \
  --robot.cameras="{front: {type: opencv, index_or_path: /dev/video0, width: 640, height: 480, fps: 30}}" \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader \
  --display_data=true
```

当前建议优先使用数字编号：

```text
index_or_path: 0
```

## 11.4 联动和镜头同时成功的判断

满足以下条件表示完整调试成功：

```text
Follower显示connected
Leader显示connected
没有出现Traceback
移动主手时从动臂同步跟随
夹爪可以同步开合
Rerun窗口正常打开
Rerun中可以看到front摄像头画面
画面持续更新，没有长时间卡住
```

# 12. 常见错误及处理

## 12.1 关节数值始终是2047

错误表现：

```text
shoulder_pan    | 2047 | 2047 | 2047
shoulder_lift   | 2047 | 2047 | 2047
elbow_flex      | 2047 | 2047 | 2047
wrist_flex      | 2047 | 2047 | 2047
gripper         | 2047 | 2047 | 2047
```

错误信息：

```text
ValueError: Some motors have the same min and max values
```

首先确认出现下面提示后，确实用手活动了关节：

```text
Recording positions. Press ENTER to stop...
```

此时不能马上按回车。

如果已经活动关节但仍保持2047，需要检查：

* 命令是否使用了正确端口；
* 机械臂电源是否打开；
* 电机ID是否正确；
* 是否有多个电机使用相同数字ID；
* 电机连接线是否松动；
* 控制板和电机波特率是否一致；
* 控制板USB线是否正常；
* 是否错误连接到了另一只机械臂。

不要在关节明显带力时强行掰动。

## 12.2 串口没有权限

错误可能包含：

```text
Permission denied
```

或者：

```text
Could not open port /dev/ttyACM1
```

把用户 `jack` 加入串口组：

```bash
sudo usermod -aG dialout jack
```

执行后必须注销Ubuntu账户并重新登录，或者重新启动电脑。

重新登录后检查：

```bash
groups jack
```

输出中应包含：

```text
dialout
```

## 12.3 找不到机械臂串口

执行：

```bash
ls -l /dev/ttyACM*
```

如果没有任何设备：

1. 检查USB线；
2. 检查USB接口；
3. 检查控制板供电；
4. 更换USB数据线；
5. 确认使用的是数据线，不是只能充电的线。

查看最新USB信息：

```bash
dmesg | tail -n 30
```

## 12.4 摄像头被占用

错误可能包含：

```text
Device or resource busy
```

查看占用摄像头的程序：

```bash
fuser /dev/video0
```

关闭以下可能占用摄像头的软件：

* 浏览器摄像头页面；
* 视频会议软件；
* Cheese；
* ffplay；
* 其他OpenCV程序；
* 上一次未正常退出的LeRobot程序。

## 12.5 摄像头无法以30帧运行

先改成15帧：

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 15}}" \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader \
  --display_data=true
```

## 12.6 缺少Rerun可视化依赖

如果出现缺少 `rerun` 或可视化组件的错误，在LeRobot目录执行：

```bash
cd ~/lerobot
pip install -e ".[feetech,viz]"
```

安装完成后重新运行带摄像头联动命令。

## 12.7 从动臂启动时突然跳动

立即按：

```text
Ctrl+C
```

必要时立即关闭从动臂电源。

然后检查：

* 主手和从动臂启动前是否处于相近姿态；
* 主手是否加载了正确的 `so101_leader` 校准；
* 从动臂是否加载了正确的 `so101_follower` 校准；
* 主手和从动臂的关节安装方向是否一致；
* 是否交换了主手和从动臂端口；
* 是否需要重新输入 `c` 校准。

# 13. 最终推荐执行顺序

## 第一步：进入环境

```bash
conda activate lerobot
cd ~/lerobot
```

## 第二步：检查端口

```bash
ls -l /dev/ttyACM*
```

## 第三步：确认摄像头

```bash
lerobot-find-cameras opencv
```

## 第四步：校准从动执行臂

```bash
lerobot-calibrate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower
```

需要重新校准时输入：

```text
c
```

## 第五步：校准主手控制臂

```bash
lerobot-calibrate \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader
```

需要重新校准时输入：

```text
c
```

## 第六步：不带摄像头测试联动

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader
```

## 第七步：单独测试摄像头

```bash
ffplay \
  -f v4l2 \
  -input_format mjpeg \
  -video_size 640x480 \
  -framerate 30 \
  /dev/video0
```

确认画面正常后，关闭ffplay。

## 第八步：机械臂加摄像头完整联动

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=so101_follower \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=so101_leader \
  --display_data=true
```

最终设备关系必须保持：

```text
从动执行臂 follower
端口：/dev/ttyACM1
校准名称：so101_follower

主手控制臂 leader
端口：/dev/ttyACM0
校准名称：so101_leader

机械臂外置摄像头
设备：/dev/video0
OpenCV编号：0
分辨率：640×480
帧率：30 FPS
```

以上命令结构与LeRobot官方的[SO-101校准说明](https://huggingface.co/docs/lerobot/so101)、[真实机器人遥操作说明](https://huggingface.co/docs/lerobot/il_robots)和[摄像头说明](https://huggingface.co/docs/lerobot/cameras)一致。
