# 07-08 - 辅助模块

> **包含包**: xline_inkjet_printer, stepper_motor_driver, xline_cmd_vel_mux, xline_ln150_driver  
> **层次**: 架构第四层 (硬件驱动)

---

## 1. xline_inkjet_printer — 喷码打印机

| 属性 | 值 |
|------|-----|
| 语言 | Python 3.10 |
| 核心文件 | `async_inkjet_node.py`, `async_tcp_client.py`, `msg_encoder.py` |
| ROS接口 | `/printer_command` Service (xline_msgs/PrinterCommand) |
| 配置 | `config/printers.yaml` |

**喷墨模式**:
- `solid` — 实线 (连续喷墨)
- `dashed` — 虚线 (间隔喷墨)
- `text` — 文字喷印

**核心流程**:
```
async_inkjet_node:
  PrinterCommand Service回调
    → 解析命令 (mode/content/printer)
    → msg_encoder: 命令→二进制消息
    → async_tcp_client: 异步TCP发送到打印机
    → 等待响应
```

**辅助功能**: 墨量查询 (`ink_level_query.py`)、配置校验 (`config_validator.py`)

## 2. stepper_motor_driver — 步进电机

| 属性 | 值 |
|------|-----|
| 核心文件 | `stepper_motor_node.py` |
| ROS接口 | `/motor_command` Service (xline_msgs/MotorCommand) |

**功能**: 控制左右两个喷码机的升降 (forward/reverse)，确保喷码时喷头与地面保持合适距离。

## 3. xline_cmd_vel_mux — 速度指令复用

| 属性 | 值 |
|------|-----|
| 核心文件 | `cmd_vel_mux.py` |

**功能**: 从多个 `/cmd_vel` 来源中按优先级选择一个输出。典型场景：
- 手动控制 (摇杆) → 高优先级
- 自动控制 (路径跟随) → 中优先级
- 避障降速 → 最高优先级

## 4. xline_ln150_driver — LN150全站仪驱动

| 属性 | 值 |
|------|-----|
| 语言 | C++17 |
| 核心文件 | `lndriver_node.cpp` |
| ROS接口 | `/ln_driver/command_srv` Service (xline_msgs/LnCommand) |
| 配置 | `config/ln.yaml` |

**支持命令**:
- `command_type=1` — 初始化全站仪
- `command_type=2` — 自动跟踪 (锁定反射板)
- `command_type=3` — 自动调平

**被调用方**:
```
xline_server robot/tcp/simple_device_server.py (TCP 9996)
  → 接收简单字符串命令 ("init_station"/"auto_track"/"auto_level")
  → 转换为 LnCommand → 调用 /ln_driver/command_srv
```

## 5. 辅助模块交互图

```
xline_base_controller
  ├── → /printer_command → xline_inkjet_printer → TCP → 喷码打印机
  ├── → /motor_command → stepper_motor_driver → 步进电机
  └── ← (cmd_vel) ← xline_cmd_vel_mux ← [摇杆/自动/避障]

xline_server (simple_device_server:9996)
  └── → /ln_driver/command_srv → xline_ln150_driver → 全站仪
```
