## 查看喷墨机有什么后台程序占领着？

```
sudo systemctl disable --now robot-service.service
sudo ss -tnp | grep '192.168.0.10:'

```

```
ps -fp 2130
systemctl status robot-service.service --no-pager
```

这三条命令分别用来查看**网络连接、进程信息和 systemd 服务状态**，都只是查询，不会修改或停止程序。

| 命令                                                  | 作用                                                                                        |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `sudo ss -tnp \| grep '192.168.0.10:'`              | 列出本机与喷码机 IP 之间的 TCP 连接，并显示对应进程。输出里的 `ESTAB` 表示连接已建立；`pid=2130` 是占用连接的进程号。                 |
| `ps -fp 2130`                                       | 查看 PID `2130` 对应进程的详细信息，例如运行用户、父进程和启动命令。                                                  |
| `systemctl status robot-service.service --no-pager` | 查看 `robot-service.service` 的运行状态、是否设置为开机启动、主进程 PID、子进程和近期日志。`--no-pager` 表示直接输出，不进入分页浏览器。 |

你贴出的结果说明：`robot-service.service` 正在运行并设置为开机启动；它的 Python 进程 `2130` 当前与喷码机的 `6000` 和 `8010` 端口保持已建立的 TCP 连接。

#### 线图的解释
"M16-19P 公座" = M16 规格、19 根针、公头（插针）
16-19P 公座是工业领域常用的**多芯圆形防水连接器**，指螺纹规格为 M16、包含 19 个插针触点的面板安装型公头插座，

#### 第2块：电源框（第一行小框）

左边颜色条 → 中间画的小接头 → 右边写功能

| 左边字母 | 颜色条写的                | 对应中间那个小接头的几号针 |
| :--: | -------------------- | :-----------: |
|  A   | 红色条：DC30V 1.5A（电源正极） |     1号、2号     |
|  B   | 蓝色条：GND（电源负极/地）      |     3号、4号     |

- 中间画的那个四针小圆圈 = 设备上的电源输入口（POWER DIN母座）
- 右边写"IN Power DC30V-1.5A" = 这个口要接30V直流电

> 意思就是：M16头上的A针脚，连到设备电源口的1、2号针；B针脚连到3、4号针。

---

#### 第3块：DB9母座框（第二行左边）

==就是那个D型9针的串口插座==，旁边画了两个并排的DB9母座。

| 左边字母 | 颜色条写的 | 对应DB9的几号针 |
|:---:|---|:---:|
| L | 红色条：12V（给传感器供电+） | 8号 |
| F | 粉色条：Sensor（传感器信号） | 2号 |
| R | 灰绿条：Encoder A（编码器A相） | 4号 |
| G | 紫色条：Encoder B（编码器B相） | 3号 |
| K | 蓝色条：GND（地） | 7号 |

- 右边写"DB9母座X2" = 设备上有两个一模一样的DB9母座
- 右边那个黄色框 = 这两个DB9口除了默认功能，还可以在设备里设置成别的功能（光眼、启停喷印、复位等）

> 这组是接**外部传感器和旋转编码器**用的，你要改线不用这组。

---

#### 第4块：RS232 + IO框（第三行左边）

==又是一个DB9，不过这个是公座（插针）==，不是母座。

| 左边字母 | 颜色条写的 | 对应DB9的几号针 |
|:---:|---|:---:|
| U | 青色条：RS-232 TXD（串口发送） | 3号 |
| M | 深青条：RS-232 RXD（串口接收） | 2号 |
| T | 蓝色条：GND（地） | 5号 |
| C | 橄榄绿条：Start/stop print（启停喷印） | 6号 |
| T | 蓝色条：GND（地） | 7号 |
| N | 棕色条：Revert（翻转方向） | 9号 |

- 右边黄色框 = 这几个针脚也可以配置成其他功能
- 这组是**串口通讯 + 控制按钮**用的，你要改线也不用这组。

---

#### 第5块：USB框（第四行）

| 左边字母 | 颜色条写的 | 对应USB口的几号针 |
|:---:|---|:---:|
| H | 红色条：USB2.0 DC5V（USB电源+） | 1号 |
| S | 紫色条：USB2.0 Data+（USB数据+） | 2号 |
| I | 棕色条：USB2.0 Data-（USB数据-） | 3号 |
| T | 蓝色条：GND（地） | 4号 |

- 中间画的那个方口 = USB-B母座（就是打印机上用的那个方口）
- 这组就是普通USB线的定义，红是5V、白是D+、绿是D-、黑是GND。

---

#### 第6块：网口框（最下面一行）

| 左边字母 | 颜色条写的 | 对应RJ45的几号针 |
|:---:|---|:---:|
| D | 橙色条：Ethernet TX D1+（网口发送+） | 1号 |
| O | 黄色条：Ethernet TX D1-（网口发送-） | 2号 |
| E | 绿色条：Ethernet TX D2+（网口发送2+） | 3号 |
| P | 绿色条：Ethernet TX D2-（网口发送2-） | 6号 |

- 中间画的就是普通网口（RJ45）
- 右边写"100Mbps" = 百兆网，不是千兆，所以只用4根线
- 对应网线里的橙白、橙、绿白、绿这四根。

### 二、只要电源 + 网口 + USB 三条线的转接表

| 要转的线 | M16 针脚 | 线数 | 接到什么接头 |
|---|---|:---:|---|
| **电源线 DC30V** | A（+）、B（GND） | 2根 | DC 电源插头（5.5mm） |
| **网口线 100M** | D（TX1+）、O（TX1-）、E（TX2+）、P（TX2-） | 4根 | RJ45 水晶头 |
| **USB 线** | H（5V）、S（D+）、I（D-）、T（GND） | 4根 | USB-B 母座（打印机口） |

> 不用的针脚（C, F, G, K, L, M, N, R, U）空着不焊就行，总共只接10根线。
