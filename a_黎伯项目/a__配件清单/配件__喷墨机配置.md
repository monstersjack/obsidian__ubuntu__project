## 查看喷墨机有什么后台程序占领着？

```
sudo systemctl disable --now robot-service.service
sudo ss -tnp | grep '192.168.0.10:'

```

```
ps -fp 2130
systemctl status robot-service.service --no-pager
```

这三条命令分别用来查看**网络连接、进程信息和 systemd 服务状态**，都只是查询，不会修改或停止程序。

| 命令                                                  | 作用                                                                                        |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `sudo ss -tnp \| grep '192.168.0.10:'`              | 列出本机与喷码机 IP 之间的 TCP 连接，并显示对应进程。输出里的 `ESTAB` 表示连接已建立；`pid=2130` 是占用连接的进程号。                 |
| `ps -fp 2130`                                       | 查看 PID `2130` 对应进程的详细信息，例如运行用户、父进程和启动命令。                                                  |
| `systemctl status robot-service.service --no-pager` | 查看 `robot-service.service` 的运行状态、是否设置为开机启动、主进程 PID、子进程和近期日志。`--no-pager` 表示直接输出，不进入分页浏览器。 |

你贴出的结果说明：`robot-service.service` 正在运行并设置为开机启动；它的 Python 进程 `2130` 当前与喷码机的 `6000` 和 `8010` 端口保持已建立的 TCP 连接。

### 二、只要电源 + 网口 + USB 三条线的转接表

| 要转的线 | M16 针脚 | 线数 | 接到什么接头 |
|---|---|:---:|---|
| **电源线 DC30V** | A（+）、B（GND） | 2根 | DC 电源插头（5.5mm） |
| **网口线 100M** | D（TX1+）、O（TX1-）、E（TX2+）、P（TX2-） | 4根 | RJ45 水晶头 |
| **USB 线** | H（5V）、S（D+）、I（D-）、T（GND） | 4根 | USB-B 母座（打印机口） |

> 不用的针脚（C, F, G, K, L, M, N, R, U）空着不焊就行，总共只接10根线。
