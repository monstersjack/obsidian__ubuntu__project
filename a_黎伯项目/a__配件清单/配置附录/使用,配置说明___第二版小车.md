##  VNC 连接说明

####  连接信息

根据客户端所在网络选择地址：

| 客户端网络 | VNC 地址 |
| --- | --- |
| `192.168.0.x` | `192.168.0.100:5901` |
| `192.168.123.x` | `192.168.123.57:5901` |

- 用户名：留空
- VNC 密码：`6`

####  Windows / Linux 连接方法

1. 打开 VNC Viewer，例如 TigerVNC Viewer、RealVNC Viewer 或 Remmina。
2. 输入服务器地址：
   - RealVNC 或 Remmina：`192.168.0.100:5901`
   - TigerVNC：`192.168.0.100:1` 或 `192.168.0.100::5901`
3. 点击连接，用户名留空，输入 VNC 密码 `6`。

如果客户端位于 `192.168.123.x` 网络，请将服务器 IP 换成 `192.168.123.57`。

####  黑屏处理

- 连接后若出现黑屏，请移动鼠标或按任意键唤醒桌面。
- 如果出现 Ubuntu 锁屏界面，请输入 `qingz` 的系统登录密码。
- 系统登录密码与 VNC 密码不同，本文档不保存系统登录密码。

####  安全提示

VNC 密码较弱，仅建议在可信局域网内临时使用，不要将 VNC 端口直接开放到公网。
