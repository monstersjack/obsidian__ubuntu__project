## 设计软件


|          | **SolidWorks**                                        | **AutoCAD**     |
| -------- | ----------------------------------------------------- | --------------- |
| **原生格式** | `.SLDPRT`（零件）   `.SLDASM`（装配体）   `.SLDDRW`（工程图）       | `.DWG`（图纸）      |
| **核心定位** | 三维建模为主，二维工程图为辅                                        | 二维绘图为主          |
| **结构**   | 一个文件包含完整的三维模型 + 参数 + 特征树                              | 纯二维矢量图形，只有线条和标注 |
| **交换格式** | 可导出 `.DXF` / `.DWG`（工程图）   可导出 `.STEP` / `.IGS`（三维模型） | 可导出 `.DXF`      |


- **SolidWorks** 输出的是**三维模型**（.SLDPRT 等），附带的二维工程图可以导出成 DWG/DXF
- **AutoCAD** 输出的是**二维图纸**（.DWG）
- 两者**唯一能互通的格式就是 DXF/DWG**，这也是为什么你的划线小车项目解析 DXF/DWG 就行——不管上游是 SolidWorks 还是 AutoCAD，导出成 DXF 后格式统一。
