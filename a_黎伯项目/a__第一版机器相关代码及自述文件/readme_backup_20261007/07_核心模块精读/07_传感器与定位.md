## 1. beiwei_imu_driver — IMU传感器驱动

| 属性 | 值 |
|------|-----|
| 位置 | `ros_pack/beiwei_imu_driver/` |
| 语言 | C++17 |
| 发布话题 | `/imu` (sensor_msgs/Imu), 100Hz |
| 配置 | `config/mins500.yaml` (串口号/波特率/坐标) |

**核心流程**:
```
main.cpp: 20Hz spin循环
  → beiwei_imu_driver.cpp: 串口读取 → 数据解码
    → imu_parser.cpp: 字节流 → sensor_msgs/Imu
      → publish /imu
```

## 2. lslidar_driver — 激光雷达驱动

| 属性 | 值 |
|------|-----|
| 位置 | `ros_pack/lslidar_driver/` |
| 发布话题 | `/lslidar_scan` (lslidar_msgs/LslidarScan), 10Hz |

**核心流程**:
```
lslidar_driver_node.cc: polling()循环读包
  → lslidar_driver.cc: UDP包 → 点云解析

```

支持单雷达和双雷达模式 (`lslidar_launch.py` / `lslidar_double_launch.py`)。

## 3. xline_localization — 定位融合

| 属性 | 值 |
|------|-----|
| 订阅 | `/imu` + `/reflector_position` + `/odom` + `/tf` |
| 发布 | `/estimated_pose` (geometry_msgs/PoseStamped), 20Hz |
| 服务 | `~/calibrate_pose` (std_srvs/Trigger) |

**融合算法**:
```
imuCallback():
  yaw = imu.orientation → euler_yaw

reflectorPositionCallback():
  robot_x, robot_y = reflector + TF(反射板→基座offset)

calcRobotPose():
  发布 /estimated_pose:
    x = robot_x, y = robot_y, θ = yaw

calibratePoseCallback():
  1. 发布cmd_vel前进 (线速度0.2m/s)
  2. 收集位置点序列
  3. fitLine(): 最小二乘拟合直线
  4. 航向 = atan(斜率)
  5. initPose(x, y, θ)
  6. 发布 /estimated_pose
```

**安全机制**: watchdogCallback() → 数据超时发布零位姿

## 4. xline_obstacle_detector — 障碍物检测

| 属性 | 值 |
|------|-----|
| 订阅 | `/lslidar_scan` |
| 发布 | `/obstacle_detected` (Float32MultiArray), `/obstacle_status` (String), `/obstacle_bool` (Bool) |
| 频率 | 10Hz |

**检测算法**:
```
laserScanCallback():
  1. 雷达点 → 机器人坐标系变换
  2. 四方向矩形碰撞检测:
     front_zone  = [x+0.5~+2.0, y-0.4~+0.4]
     back_zone   = [x-0.5~-2.0, ...]
     left_zone   = [y+0.3~+1.0, ...]
     right_zone  = [y-0.3~-1.0, ...]
  3. 屏蔽区域过滤 isInMaskZone()
  4. 各方向最近距离 getMinObstacleDistanceInDirection()
  5. publishObstacleStatus()
```

**配置参数**: 检测距离、机器人尺寸、雷达安装位置、屏蔽角度/范围

## 6. LN150 全站仪 —— 补充说明

### 6.1 什么是全站仪

**全站仪**（Total Station）是一种集**电子经纬仪**和**光电测距仪**于一体的高精度测绘仪器。LN150 是中海达（Hi-Target）生产的一款高精度工程全站仪。

| 能力 | 说明 |
|------|------|
| **角度测量** | 水平角 + 垂直角，精度可达 1"（角秒） |
| **距离测量** | 激光测距，通过反射板可达数百米 |
| **自动追踪** | 锁定反射板后可自动追踪目标移动 |
| **数据输出** | 串口/TCP 实时输出测量数据 |

### 6.2 在全站仪定位中为什么需要反射板

全站仪通过发射激光束并接收反射光来测量距离。机器人上安装**反射板（Reflector）**的作用：

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   LN150 全站仪                                                │
│   (固定在地面已知坐标点)                                       │
│       │                                                      │
│       │ 发射激光束                                            │
│       │ 测量角度（水平角 α、垂直角 β）                          │
│       │ 测量距离 d（通过激光往返时间）                          │
│       │                                                      │
│       ▼                                                      │
│   ┌─────────────────┐                                        │
│   │   反射板          │  ← 安装在机器人上（如顶部桅杆）         │
│   │   (角反射器/棱镜) │    将激光原路反射回全站仪               │
│   └────────┬────────┘                                        │
│            │                                                 │
│            │ TF 变换 (反射板 → 基座 offset)                    │
│            ▼                                                 │
│      机器人中心 (base_link)                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**定位计算**：
```
设全站仪坐标为 (x₀, y₀, z₀)，测量结果：
  d = 斜距
  α = 水平角
  β = 垂直角

反射板坐标：
  reflecor_x = x₀ + d × cos(β) × cos(α)
  reflecor_y = y₀ + d × cos(β) × sin(α)
  reflecor_z = z₀ + d × sin(β)

机器人中心坐标（通过 TF 静态变换）：
  robot_x = reflecor_x + offset_x
  robot_y = reflecor_y + offset_y
```

### 6.3 全站仪在 X-LINE 定位融合中的角色

```
┌──────────────────────────────────────────────────────────────┐
│                    xline_localization                        │
│                                                              │
│  数据源              频率        作用                        │
│  ─────────────────────────────────────                       │
│  /imu              100Hz    → 提供航向角 (yaw)               │
│  /odom              50Hz    → 提供局部里程计                  │
│  /reflector_position 10Hz   → 提供绝对位置 (x, y)            │
│                                                              │
│  融合输出: /estimated_pose (20Hz)                            │
│    x = reflector_x + offset   ← 绝对位置来自全站仪            │
│    y = reflector_y + offset   ← 绝对位置来自全站仪            │
│    θ = imu.yaw                ← 航向来自 IMU                 │
│                                                              │
│  ★ 核心思想：                                                │
│    全站仪 = 绝对位置（厘米级，无累积误差）                      │
│    IMU    = 航向（高频，但有漂移）                             │
│    里程计 = 局部位移（高频，但有累积误差）                      │
│                                                              │
│    三者互补，实现高精度 + 高频的定位                          │
└──────────────────────────────────────────────────────────────┘
```

### 6.4 为什么需要全站仪定位

| 对比维度 | 纯里程计 | 纯IMU | GNSS/GPS | 全站仪 |
|----------|---------|-------|----------|--------|
| **绝对精度** | 差（累积漂移） | 差（积分漂移） | 米级 | **厘米级** |
| **更新频率** | 50Hz | 100Hz | 1-10Hz | 10Hz |
| **室内可用** | ✅ | ✅ | ❌ | ✅ |
| **受遮挡影响** | 无 | 无 | 有 | **有（需通视）** |
| **成本** | 低 | 低 | 低 | 高 |

全站仪的核心价值在于**室内高精度绝对定位**——在 GNSS 不可用的室内/地下场景，提供厘米级的全局参考坐标。

### 6.5 全站仪定位的局限与应对

| 局限 | 影响 | X-LINE 的应对措施 |
|------|------|-----------------|
| **需要通视条件** | 遮挡时数据丢失 | watchdogCallback() 检测超时，切换到纯里程计模式 |
| **单目标追踪** | 只追踪一个反射板 | 机器人上安装一个反射板即可 |
| **更新频率较低** | 10Hz，无法满足控制闭环 | 与 100Hz IMU + 50Hz 里程计融合 |
| **安装标定复杂** | 全站仪需固定在已知坐标点 | 姿态校准 (calibrate_pose) 自动补偿安装误差 |

### 6.6 驱动包说明

| 属性 | 值 |
|------|-----|
| **包名** | `xline_ln150_driver` |
| **语言** | C++ |
| **通信** | 串口或 TCP 与 LN150 通信 |

| **输出** | 反射板位置数据 → xline_localization 订阅 |

### 6.7 简单理解

**全站仪就像是给机器人装了一个"室内 GPS"**：

- 🛰️ 以厘米级精度告诉你"你在哪"（绝对坐标）
- 🎯 通过追踪机器人上的反射板来实现
- 🔄 与 IMU/里程计互补，提供完整的高精度定位
- ⚠️ 但需要保持通视（全站仪和反射板之间不能有遮挡）
