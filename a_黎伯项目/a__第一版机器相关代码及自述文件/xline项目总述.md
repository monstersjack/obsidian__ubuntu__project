最终实现的功能效果是，
划线工作流：
1. 将要划线的地图转化成（Json格式）地图（小车后端），然后调用ros2软件包拆解划线地图的路径实现，拆分成数个路径点（带坐标的路径点）。然后给用户确认划线
2. 小车执行一个划线（ros的动作）持续行动，按照路径点一个一个画，实现划线，
3. 

| CAD界面图纸设计         | 小车在APP界面上提供划线界面设计                                                                 |
| ----------------- | --------------------------------------------------------------------------------- |
| AI交互功能            | 小车APP上提供语音交互功能，提供调用现有大模型，调用例如DeepSeek，能够通过交互功能的实时，掌控小车的状态，控制小车行走，实现小车划线agent功能的实现 |
| AI图纸设计加最终实现划线任务闭环 | 通过调用大模型生成图片，然后再将图片矢量化，（简化图片结构，实现输出图片轮廓）最终将画图的路径点输出到用户界面，给用户进行确认。                  |

| AI交互界面实现记忆力   | 在小车的后端或者云端，实现建立数据库，保留记忆力，再通过RAG，搜索增强生成数据库的内容。 |
