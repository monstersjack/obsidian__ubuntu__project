## 一、项目概述与核心功能

**X-LINE** 是一个基于 ROS 2 Humble 的 **智能地面喷码机器人系统**。核心功能是接收CAD图纸 → 解析几何图元 → 生成栅格地图 → 规划绘图路径（含转场）→ 控制机器人沿路径运动并同步喷码。

│  │ xline_server │────→│   上位应用/Web    │    │  cad_transformed │  │

### 模块二：运动控制层

---

#### 📄 `wheels_driver/wheels_driver/run_motor.py` ⭐
- **功能**：**两轮差速驱动核心节点**，实现完整运动控制闭环
- **实现原理**：

  ```
  cmd_vel(Twist) → 逆运动学 → 左轮速度 / 右轮速度 → iWMC伺服轮
  编码器反馈 → 正运动学 → 里程计(odom) + TF变换
  ```

- **关键代码逻辑**：
  - **逆运动学**：`v_left = v - (L/2)×ω`, `v_right = v + (L/2)×ω`
  - **正运动学**：`v = (v_left+v_right)/2`, `ω = (v_right-v_left)/L`
  - **里程计更新**：使用解析积分（区分直线/曲线运动），角度不限幅以支持多圈旋转
  - **超时保护**：cmd_vel超时自动置零停车，防止断联跑车
  - **速度限幅**：clamp到最大线速度/角速度
- **在架构中的角色**：硬件抽象层的核心，将ROS速度指令转换为电机控制

#### 📄 `wheels_driver/wheels_driver/iwmc_servo_control.py` ⭐
- **功能**：iWMC集成式伺服轮CANopen协议控制类
- **实现原理**：
  - 通过SLCAN串口实现CANopen协议通信
  - 完整状态机：NOT_READY → SWITCH_ON_DISABLED → READY → SWITCHED_ON → OPERATION_ENABLED
  - 单位换算：`DEC = RPM × 512 × EncoderResolution / 1875`
- **关键逻辑**：
  - `enable_servo()`: 执行状态机转换（Shutdown→Switch On→Enable Operation），最多5次重试
  - `set_target_velocity_rpm()`: RPM→DEC转换后写0x60FF对象字典
  - 支持仿真模式（simulation_mode），不需硬件即可调试
- **在架构中的角色**：电机驱动的核心抽象层

#### 📄 `wheels_driver/wheels_driver/slcan_comm.py`
- **功能**：SLCAN串口通信底层，封装CANopen SDO读写

#### 📄 `wheels_driver/wheels_driver/waveshare_can.py`
- **功能**：Waveshare CAN适配器驱动

#### 📄 `wheels_driver/config/differential_wheels_params.yaml`
- **功能**：差速驱动参数（轮半径、轮距、编码器分辨率、减速比、速度限制等）

---

#### 📄 `stepper_motor_driver/stepper_motor_driver/stepper_motor_node.py`
- **功能**：步进电机控制节点（控制左右喷码机上下移动）
- **在架构中的角色**：喷码机硬件控制

---

#### 📄 `xline_base_controller/src/base_controller_node.cpp`
- **功能**：基座控制节点入口，使用 `MultiThreadedExecutor` 启动 `MotionControlCenter`
- **关键逻辑**：多线程执行器以支持Action服务器并发处理

#### 📄 `xline_base_controller/include/xline_base_controller/motion_control_center.hpp` ⭐⭐
- **功能**：**运动控制中枢**，整个系统的核心调度器
- **实现原理**：
  - 作为 ROS 2 Action Server 提供 `execute_plan` 动作
  - 接收JSON格式执行计划，解析为 `LineData/CircleData/ArcData/SplineData/EllipseData`
  - 调度四种跟随控制器：`LineFollowController`、`RPPController`、`LQRCircleController`、`LQRCurveController`
  - 协调喷码机（InkjetClient）和步进电机的同步控制
- **关键逻辑**：
  - `handleGoal()`: 接受/拒绝执行目标（正在执行则拒绝）
  - `execute()`: 主执行循环，逐条处理路径，每次循环：检查暂停 → 计算速度 → 发布cmd_vel → 检查目标到达
  - `compute_velocity()`: 根据路径类型选择控制器，调用对应方法生成速度指令
  - `handlePauseService()`: 暂停/恢复服务
  - `extractLineData/CircleData/ArcData/SplineData/EllipseData`: JSON数据解析
  - 喷墨模式：solid（实线）、dashed（虚线）、text（文字）
- **在架构中的角色**：连接"规划"与"执行"的核心桥梁

#### 📄 `xline_base_controller/src/motion_control_center.cpp`
- **功能**：MotionControlCenter的完整实现

#### 📄 `xline_base_controller/include/xline_base_controller/inkjet_client.hpp`
- **功能**：喷码机客户端封装，控制喷码开始/停止和模式切换

### 模块三：路径规划与跟踪层（核心算法包）

---

#### 📄 `xline_path_planner/include/xline_path_planner/common_types.hpp` ⭐
- **功能**：定义所有几何数据结构，是整个规划系统的**数据基础**
- **包含结构体**：

  | 结构体 | 继承 | 用途 |
  |--------|------|------|
  | `Point2D` | - | 二维点（含距离计算、运算符重载） |
  | `Point3D` | Point2D | 三维点（含向量运算） |
  | `Vector2D` | - | 二维向量（模长、归一化、点积） |
  | `Line` | - | 直线（start/end/length + 元数据） |
  | `Polyline` | Line | 多段线（vertices数组） |
  | `Spline` | Line | 样条（control_points/knots/weights） |
  | `LineSegment` | Line | 多段线拆分后的线段 |
  | `MergedLine` | Line | 共线合并后的虚拟线段 |
  | `Curve` | Line | 曲线（预留Bézier/NURBS扩展） |
  | `Circle` | Line | 圆（center+radius） |
  | `Arc` | Circle | 圆弧（start_angle+end_angle） |
  | `Ellipse` | Line | 椭圆/椭圆弧 |
  | `Text` | Line | 文字元素 |

- **枚举定义**：`GeometryType`、`RouteType`、`PrinterType`、`InkMode`、端点切线模式等

#### 📄 `xline_path_planner/include/xline_path_planner/cad_parser.hpp`
- **功能**：CAD JSON解析器，将 `cad_transformed.json` 解析为 `CADData`
- **支持类型**：line、polyline、circle、arc、ellipse、spline、text
- **关键逻辑**：
  - 按图层分类：空洞→hole_lines、障碍→obstacle_lines、路径→path_lines
  - 单位换算：默认毫米→米（factor=1000）
  - 角度自动识别：>2π视为度并转弧度
  - `build_layer_map()`: 构建layer_id→name映射

#### 📄 `xline_path_planner/include/xline_path_planner/geometry_preprocessor.hpp`
- **功能**：几何预处理器
- **处理内容**：Polyline拆分、共线线段合并、路径扩展（起终点延长）

#### 📄 `xline_path_planner/include/xline_path_planner/grid_map_generator.hpp`
- **功能**：栅格地图生成器，将CAD几何图元光栅化为占用栅格
- **核心算法**：
  - **Bresenham直线光栅化**：将线段离散到栅格
  - 圆弧/椭圆/样条：先离散为点序列再光栅化
  - **De Casteljau算法**：计算贝塞尔曲线点
  - NURBS点计算
- **输出**：`vector<vector<int>>` 栅格地图（0=空闲, 1=障碍物）

#### 📄 `xline_path_planner/include/xline_path_planner/path_planner.hpp` ⭐⭐
- **功能**：**路径规划主类**，从CAD数据生成执行路径
- **核心方法**：
  - `plan_paths()`: 主入口，规划所有路径（绘图路径+转场路径）
  - `processGeometryGroup()`: 处理一组线段
  - `planGeometryPath()`: 规划单条绘图路径，应用偏移
  - `planConnectionPath()`: 规划转场路径（支持贝塞尔曲线）
  - `findNearestUnprocessedLine()`: 贪心算法找最近未处理线段
  - `applyPathOffset()`: 路径偏移（左侧/右侧/居中）
  - `generate_cubic_bezier_transition()`: 三次贝塞尔转场
  - `generate_quintic_bezier_transition()`: 五次贝塞尔转场（曲率连续，更平滑）
  - `visualize_paths()`: 路径可视化并保存图片
- **贝塞尔转场特性**：
  - 自适应控制点距离（基于起点/终点朝向）
  - 曲率控制（最小转弯半径约束）
  - 大角度支持（>90°自动boost控制点比例）
  - 三种终点切线模式：ALIGN_PATH / ALIGN_STRAIGHT / BLEND

#### 📄 `xline_path_planner/include/xline_path_planner/trajectory_generator.hpp`

#### 📄 `xline_follow_controller/include/xline_follow_controller/common/follow_common.hpp` ⭐⭐
- **功能**：**所有控制器的核心基础设施**，包含全套滤波器和控制器
- **类定义**：

| 类 | 功能 | 算法 |
|----|------|------|
| **`HampelFilter`** | 异常值检测与处理 | 基于MAD中位数绝对偏差，支持4种策略：替换中位数/软阈值/线性预测/指数衰减 |
| **`SavitzkyGolayFilter`** | 数据平滑 | 多项式拟合卷积系数，Eigen矩阵求逆 |
| **`PIDController`** | PID控制 | 标准PID + 积分限幅 + 输出限幅 |
| **`SecondOrderSmoother`** | 二阶平滑 | 质量-弹簧-阻尼系统模型，wn×wn×(u-x)-2ζ×wn×x' |
| **`FourthOrderLowpassFilter`** | 四阶低通滤波 | 巴特沃斯4阶，支持直接型和双二阶级联两种实现 |

- **HampelFilter异常值策略对比**：
  - `LINEAR_PREDICTION`（默认推荐）：基于有效历史值的加权线性趋势预测，运动连续性最佳
  - `SOFT_THRESHOLD`：Sigmoid混合原始值与中位数
  - `EXPONENTIAL_DECAY`：渐进修正到中位数
  - `REPLACE_MEDIAN`：直接用中位数替换

#### 📄 `xline_follow_controller/include/xline_follow_controller/common/base_follow_controller.hpp`
- **功能**：跟随控制器基类，定义统一接口
- **虚接口**：`setPlan()` / `computeVelocityCommands()` / `isGoalReached()` / `cancel()`

#### 📄 `xline_follow_controller/include/xline_follow_controller/line_follow/line_follow_controller.hpp` ⭐
- **功能**：**直线/折线跟随控制器**
- **状态机**：`IDLE → ALIGNING_START → FOLLOWING_PATH → ALIGNING_END → GOAL_REACHED`
- **算法特点**：
  - 线速度：Sigmoid曲线加速/减速（`accel_sigmoid_k`/`decel_sigmoid_k`参数控制平滑度）
  - 角速度：PID + Hampel + Savitzky-Golay + 二阶平滑器 四层滤波
  - 支持后退模式（`back_follow_`）
  - 路径延长（0.5m缓冲区保证终点对齐）
  - 短路径检测：动态调整对齐距离和加减速距离
  - 转场路径优化：放宽进入跟随阶段的条件

#### 📄 `xline_follow_controller/include/xline_follow_controller/rpp_follow/rpp_follow_controller.hpp` ⭐
- **功能**：**Regulated Pure Pursuit (RPP) 控制器**
- **算法完整流程**：

  ```
  当前位姿 → 裁剪已走路径 → 计算前瞻距离(速度相关) → 找前瞻点(插值) →
  曲率约束(弯道减速) → 接近目标减速 → 角速度平滑滤波 → 生成cmd_vel
  ```

- **核心方法**：
  - `getLookAheadDistance(speed)`: 前瞻距离 = k×speed + min_lookahead
  - `pruneGlobalPlan()`: 裁剪已走过的路径段
  - `getLookAheadPoint()`: 在前瞻距离处找最近路径点，必要时线性插值
  - `applyCurvatureConstraint()`: 曲率越大速度越低
  - `applyApproachConstraint()`: 接近目标时渐进减速
  - `performYawPrealignment()`: 圆轨迹切入前的航向预对准
  - `smoothAngularVelocity()`: 基于前瞻距离和角度的动态平滑
- **策略模式**：通过 `PathStrategy` 抽象在 `CirclePathStrategy` 和 `CurvePathStrategy` 之间切换

## 五、构建流程与部署方式

### 5.1 构建方式

```bash
# 1. 创建工作空间
mkdir -p ~/xline_ws/src
cp -r ros_pack/* ~/xline_ws/src/

# 2. 安装ROS 2 Humble依赖
cd ~/xline_ws
rosdep install --from-paths src --ignore-src -r -y

# 3. 编译
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release

# 4. 加载环境
source install/setup.bash
```

### 5.2 部署方式

```bash
# 设置工作空间根目录（可选，用于分离代码和数据）
export XLINE_WS_ROOT=/home/jack/xline_ws

# 启动完整系统
ros2 launch xline_base_controller base_controller.launch.py

# 或者分别启动各组件
ros2 run wheels_driver run_motor &
ros2 run beiwei_imu_driver beiwei_imu_driver_node &
ros2 run xline_localization localization_node &
ros2 run xline_base_controller base_controller_node &
python3 -m xline_server &
```

## 六、运行机制与数据流

### 6.1 完整作业流程

```
1. 用户通过API上传CAD文件(DXF/DWG)
         │
         ▼
2. xline_server 文件同步 → 触发CAD转换
         │
         ▼
3. xline_path_planner (plan_path Service):
   ├── CADParser: 解析cad_transformed.json → 几何图元
   ├── GeometryPreprocessor: 拆分Polyline, 合并共线, 扩展路径
   ├── GridMapGenerator: 光栅化 → 占用栅格地图
   ├── PathPlanner: 贪心排序 → 绘图路径 + 贝塞尔转场
   ├── TrajectoryGenerator: 路径点 → 执行节点(含打印机类型)
   └── OutputFormatter: → planned_results/planned_*.json
         │
         ▼
4. xline_server 读取计划JSON → 通过ExecutePlan Action发送
         │
         ▼
5. MotionControlCenter (execute_plan Action):
   ├── 解析JSON → Line/Circle/Arc/Spline/Ellipse
   ├── 选择控制器: LineFollow / RPP / LQR
   ├── computeVelocityCommands() → cmd_vel
   ├── 同步控制: 喷码机 + 步进电机
   └── 逐条执行，发布反馈(feedback.current_id)
         │
         ▼
6. wheels_driver 接收cmd_vel:
   ├── 逆运动学 → 左轮RPM / 右轮RPM
   ├── iWMC CANopen → 电机执行
   ├── 编码器反馈 → 正运动学
   └── 发布 odom + TF
         │
         ▼
7. xline_server 监控执行状态 → WebSocket实时推送 → 前端展示
```

### 6.2 Topic / Service / Action 拓扑

| 通信方式 | 名称 | 方向 | 类型 |
|----------|------|------|------|
| Topic | `/cmd_vel` | base_controller → wheels_driver | `Twist` |
| Topic | `/odom` | wheels_driver → localization | `Odometry` |
| Topic | `/imu` | beiwei_imu → localization | `Imu` |
| Topic | `/estimated_pose` | localization → base_controller | `PoseStamped` |
| Action | `/execute_plan` | execution_manager → base_controller | `ExecutePlan` |
| Service | `/plan_path` | xline_server → path_planner | `PlanPath` |
| Service | `/execution/pause` | execution_manager → base_controller | `Trigger` |
| Service | `/execution/resume` | execution_manager → base_controller | `Trigger` |
