```
项目根目录
├── README.md              # 【核心主文件】项目自述主入口，所有用户的第一阅读入口
├── LICENSE                # 【必填合规文件】项目开源/使用许可协议
├── CHANGELOG.md           # 【推荐配套文件】版本变更日志，记录全版本迭代内容
├── CONTRIBUTING.md        # 【开源项目必填】贡献指南，规范社区参与流程
├── CODE_OF_CONDUCT.md     # 【大型项目必备】社区行为准则，约定交流与协作规范
├── SECURITY.md            # 【推荐配套文件】安全漏洞上报与处置说明
├── FAQ.md                 # 【可选配套文件】高频常见问题汇总
└── docs/                  # 【复杂项目必备】详细文档目录，承接README的深度内容
    ├── README.md          # 文档站点入口
    ├── installation.md    # 详细安装指南
    ├── user_guide.md      # 完整用户使用手册
    ├── api_reference.md   # API/接口参考文档
    └── architecture.md    # 项目技术架构与实现原理详解
```
