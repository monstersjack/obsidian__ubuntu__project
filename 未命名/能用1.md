# "青航察打" — 从南方果园到东北粮仓的精准农业无人机系统

## 项目故事全文

---

### 一、项目缘起：从柑橘园出发的技术初心

华南农业大学"青航"团队长期深耕南方丘陵果园精准植保领域，针对柑橘园这一典型的**离散型、非连续种植场景**——果树呈规则行列分布但存在株间间隙、缺株断行、树冠稀疏不均等复杂情况——自主研发了一套**"察打一体"无人机精准作业系统**。该系统集成了三大核心技术：

- **BP-PINN雾滴飘移控制系统**：基于物理信息神经网络，根据实时风速自动调节离心喷头转速控制雾滴粒径，减少飘移损失
- **YOLACT++-DANet冠层体积分级变量施药系统**：双目相机实时识别柑橘树冠体积（V1-V5五级），PWM控制离心喷头实现按需喷施
- **UASS风场-冠层时空作用模型**：Informer时序深度学习预测旋翼风对树冠的扰动，优化飞行参数

此外，团队成员马昊然的毕业论文进一步验证了**改进YOLOv8-seg实例分割**（引入DCN可变形卷积+EMA多尺度注意力）和**预响应触发控制**机制（将端到端延迟转化为空间提前量，解决"前缘欠喷、空隙误喷"问题），在田间试验中实现了非目标区地面沉积从28.71%降至2.73%的显著效果。

这些技术在南方柑橘园实现了"发现即打、精准到株"的智能植保能力，有效解决了传统均匀喷洒方式农药利用率不足30%的痛点。

然而，中国粮食安全的"压舱石"不在南方果园，而在东北黑土地。黑龙江作为全国第一粮食大省，粮食产量连续多年位居全国首位，其中友谊农场作为国家级现代化农业示范区，承载着水稻、大豆、玉米三大主粮作物的大规模种植。面对"发展现代化大农业，加快推进农业农村现代化，当好国家粮食稳产保供'压舱石'"的时代召唤，团队提出：**将南方果园积累的察打一体智能技术，创新性迁移至东北大面积粮食作物种植场景，构建以高光谱感知为驱动的"察-析-打-验"闭环精准农业无人机系统。**

### 二、核心创新：为什么需要高光谱？—— 超越人眼的"植物体检"

#### 2.1 传统感知手段的局限

| 感知手段              | 能看到什么                                       | 看不到什么          | 预警时机                   |
| ----------------- | ------------------------------------------- | -------------- | ---------------------- |
| **人眼巡视**          | 叶片变黄、枯萎、倒伏                                  | 内部生化变化         | 显性症状出现后（已错过最佳防治期）      |
| **普通RGB相机**       | 颜色变化（绿→黄→褐）                                 | 叶绿素含量具体数值、氮素水平 | 与肉眼类似，仅略早              |
| **多光谱相机**         | NDVI等粗略长势指标                                 | 精细生化参数定量值      | 提前1-2天                 |
| **高光谱成像仪（128波段）** | **叶绿素a/b精确含量、N/P/K养分水平、含水量、光合效率、病虫害种类及严重度** | —              | **提前3-7天（隐性胁迫阶段即可检测）** |

高光谱成像技术（HSI）由于其极高的光谱分辨率（128个连续波段，覆盖400-1000nm），能够捕捉到植物微弱的生理变化。与普通RGB相机只能看颜色、多光谱只能看轮廓相比，高光谱数据可以被视为植物的**"光谱指纹"**，能够非破坏性地提取大量精细的植株生长数据。

#### 2.2 高光谱能提取的关键植株数据（五大维度）

**维度一：生化组分数据（植物体内的"化学工厂"状态）**

这是高光谱最核心的优势，通过特定波长的吸收和反射特征，精确量化植物内部化学成分：

- **色素含量**：叶绿素a和b、类胡萝卜素、花青素等 → 直接反映光合能力和衰老情况
- **养分水平**：氮（N）、磷（P）、钾（K）含量 → 通过分析"红边位置"（Red Edge）的移动，可**极早期发现氮素缺乏**
- **含水量**：叶片含水量（LWC）和冠层含水量 → 高光谱在短波红外（SWIR）波段对水分极其敏感，能反映植物是否处于干旱胁迫
- **干物质与碳组分**：淀粉、可溶性糖、木质素和纤维素含量

**维度二：生物物理与形态参数（植株的"体型"与"结构"）**

- **叶面积指数（LAI）**：反映植株繁茂程度和受光面积
- **生物量（Biomass）**：植株干重或鲜重估算，是预测产量的核心指标
- **植株高度与冠层结构**：冠层覆盖度、通透性以及植株生长的空间均匀性
- **覆盖度（Fractional Vegetation Cover）**：地面被绿色植被覆盖的比例，用于评估早期出苗率

**维度三：生理机能数据（植物的"代谢"效率）**

- **光合作用参数**：净光合速率（Pn）、蒸腾速率（Tr）、气孔导度（Gs）
- **光利用效率（LUE）**：通过光化学植被指数（PRI）反映植物对光能的转化效率
- **日光诱导荧光（SIF）**：在760nm附近间接提取，监测光合作用的"金标准"

**维度四：健康与逆境预警（植物的"病症"早期诊断）**

高光谱可以在**人眼看到病斑或枯萎前（隐性胁迫阶段）**检测到问题：

- **病虫害监测**：不同病原体（真菌、病毒）导致特定光谱畸变，可识别病害种类及严重程度
- **逆境诊断**：区分缺水、盐碱胁迫、热胁迫还是重金属污染
- **杂草识别**：利用细微光谱差异，在田间精准区分农作物与外观相似的杂草

**维度五：表型与发育评价**

- **生育期识别**：准确判断植株处于幼苗期、分蘖期、开花期还是成熟期
- **品种筛选**：比较不同品种的抗逆性、光合效率，筛选优良性状
- **产量估算**：综合所有参数建立回归模型，在收获前数周甚至数月预测最终产量

#### 2.3 高光谱 vs 普通相机：为什么不可替代？

| 特征 | 普通RGB/多光谱相机 | 高光谱成像仪（128波段） |
|:---|:---|:---|
| **感官对比** | 只能看到植物"变黄了"或"干了" | 能看到"叶绿素降了20%"或"氮素利用效率低" |
| **预警时间** | 显性症状出现后（往往已错过最佳防治期） | 隐性阶段即可发现，**提前3-7天预警** |
| **精准度** | 只能定性（好或不好） | 可以**定量**（具体浓度、数值） |
| **变量施药决策** | 只能全田统一喷施 | 可精确到每平方米给出差异化施药/施肥处方 |

### 三、东北大田闭环体系：从"察"到"验"的完整作业链

#### 3.1 闭环总体架构

本系统的核心创新在于构建了**"察-析-打-验"四环节闭环**，这是原有南方果园"察打一体"概念在大面积作物场景下的系统性升级：

```
                    ┌─────────────────────────────────────┐
                    │          闭环迭代优化引擎              │
                    │  (作业效果反馈 → 模型自学习更新)        │
                    └───────────────┬─────────────────────┘
                                    │
         ┌──────────────────────────┼──────────────────────────┐
         ↓                          ↓                          ↓
   ┌───────────┐             ┌───────────┐             ┌───────────┐
   │  第一阶段  │             │  第二阶段  │             │  第三阶段  │
   │   "察"    │  ──────→   │   "析"    │  ──────→   │   "打"    │
   │  全域感知  │  高光谱数据  │  智能决策  │  处方图+    │  精准执行  │
   │          │             │          │  作业指令    │          │
   └───────────┘             └───────────┘             └─────┬─────┘
                                                           │
                                                           ↓
                                                    ┌───────────┐
                                                    │  第四阶段  │
                                                    │   "验"    │
                                                    │  效果评估  │
                                                    └───────────┘
```

#### 3.2 第一阶段 —— "察"：高光谱全域感知

**目标**：对友谊农场目标地块进行**全地面、全范围的光谱采集**，获取作物"光谱指纹"。

**作业方式**：
- 无人机搭载128波段高光谱成像仪（覆盖400-1000nm，光谱分辨率3nm），按规划航线在作物冠层上方30m高度等速巡航
- 同步搭载风速/风向传感器采集实时风场数据
- 配合双目RGB相机获取冠层高度/结构信息（复用青航原有双目立体视觉系统）
- 单次巡航覆盖500-1000亩，生成田块级高光谱数据立方体（128波段 × 空间像素 × 空间像素）

**高光谱数据预处理流程**：
1. **辐射校正**：利用标准白板参考数据将原始DN值转换为反射率
2. **几何校正**：结合RTK定位数据和IMU姿态信息，消除飞行姿态引起的几何畸变
3. **大气校正**：采用FLAASH或6S模型消除大气散射和吸收影响
4. **拼接镶嵌**：将多航带数据拼接为完整的田块级高光谱影像

**高光谱植被指数计算**（关键决策依据）：

| 植被指数 | 计算公式 | 反映的信息 | 对应决策 |
|---------|---------|-----------|---------|
| NDVI | (R_NIR - R_Red)/(R_NIR + R_Red) | 广义长势 | 长势分级（V1-V5） |
| GNDVI | (R_NIR - R_Green)/(R_NIR + R_Green) | 叶绿素含量（更敏感） | 氮肥追施量决策 |
| REIP | 红边拐点位置（680-750nm） | 氮素营养状况 | 早期缺氮预警 |
| PRI | (R_531 - R_570)/(R_531 + R_570) | 光合效率 | 胁迫程度评估 |
| NDWI | (R_860 - R_1240)/(R_860 + R_1240) | 含水量 | 灌溉/干旱预警 |
| DSI | (R_NIR - R_Red)/(R_NIR + R_Red) × R_Green/R_NIR | 病害严重度 | 病虫害靶向施药 |

**关键创新点**：传统果园系统中，"察"的感知对象是**离散的果树个体**（有没有树、树冠多大）。在东北大田中，"察"的感知对象是**连续的作物冠层面**，但其中隐藏着**"健康-病害"、"旺长-弱苗"、"需肥-不缺肥"等功能性斑块交替**——这些本质上仍是离散分布的"靶标"。高光谱的独特价值在于：它能在这些斑块**尚未表现出可见症状时（隐性胁迫阶段）**就将其识别出来，实现"治未病"。

#### 3.3 第二阶段 —— "析"：多模态智能决策

将高光谱采集的128维光谱数据转化为可执行的农业决策，是整个闭环的核心智能环节。

**(a) 长势分级引擎（迁移自冠层体积分级技术）**

将青航原系统的"冠层体积V1-V5分级"迁移为大田**"长势V1-V5分级"**：
处方图

| 分级 | 高光谱特征 | 作物状态 | 对应喷施策略 |
|------|-----------|---------|-------------|
| V1 | LAI<2.0, SPAD<30, REIP蓝移明显 | 长势弱/缺素严重 | 增施氮肥+叶面肥（150%基准量） |
| V2 | LAI 2.0-3.0, SPAD 30-35 | 长势偏弱 | 适量追肥（120%基准量） |
| V3 | LAI 3.0-4.5, SPAD 35-42 | 正常生长 | 标准施药/施肥（100%基准量） |
| V4 | LAI 4.5-6.0, SPAD 42-48 | 长势偏旺 | 减施（70%基准量） |
| V5 | LAI>6.0, 倒伏风险高 | 旺长区 | 控施+喷施控旺剂（50%基准量） |

技术迁移路径：原系统用YOLACT++-DANet对树冠体积进行五级分类 → 迁移后，**高光谱植被指数直接输出长势等级**，DANet注意力机制转用于区分作物与杂草、识别倒伏区域、感知冠层均匀性变化。

**(b) 病虫害斑块检测（创新迁移）**

- 利用高光谱DSI（病害严重度指数）结合YOLACT++-DANet实例分割模型，在大田连续冠层中精准识别**病虫害斑块**
- 训练数据替换为：水稻稻瘟病斑块、大豆灰斑病斑块、玉米大斑病斑块等
- DANet的空间注意力+通道注意力机制增强对病害斑块边缘的精细分割
- **预响应触发控制**直接复用：无人机飞经健康区时减药/停药，接近病害斑块时提前触发（补偿端到端延迟），确保斑块前缘不欠喷、健康区不误喷

**(c) BP-PINN飘移风险评估（大田风场升级）**

原模型适用于果园近地面风场。东北大田需升级为**大气边界层表面层风场模型**：
- 风速廓线：$u(z) = \frac{u_*}{k} \ln(\frac{z}{z_0})$，不同作物粗糙高度不同（水稻$z_0 ≈ 0.05m$，玉米$z_0 ≈ 0.15m$）
- 飘移控制双目标优化：$L = \alpha \cdot L_{drift} + \beta \cdot L_{penetration}$（防飘移 + 促穿透）
- 根据处方图中标定的喷施区域位置和环境风速，自动调节离心喷头转速，改变雾滴粒径，使雾滴精准沉积在目标区域

**(d) 风场-冠层响应建模（飞行参数自适应）**

将原Informer时序模型针对三种大田作物分别训练，建立**作物类型-飞行参数-冠层扰动-沉积效果**的映射：

| 作物 | 株高 | 冠层结构 | 推荐飞行高度 | 推荐飞行速度 | 风场响应特征 |
|------|------|---------|-------------|-------------|-------------|
| 水稻 | 60-100cm | 细长叶片，密集 | 1.5-2m（低飞增强穿透） | 4-6m/s（中高速） | 易弯曲，下洗穿透好，但易倒伏 |
| 大豆 | 40-80cm | 宽叶，中等密度 | 2-2.5m | 3-5m/s（中速） | 中等抗风，雾滴截留率高 |
| 玉米 | 150-280cm | 高大，叶片宽且硬 | 2.5-3m（利用下洗穿透） | 2-4m/s（低速） | 需强下洗穿透，中后期冠层阻隔严重 |

**倒伏预警**：玉米灌浆后期和大豆结荚期倒伏风险高。风场-冠层模型自动限制可能导致倒伏的飞行参数组合（如玉米灌浆期避免低飞高速）。

**最终输出**：田块级处方图（Prescription Map），分辨率1m×1m，每个像素包含：
- 施药/施肥推荐量
- 推荐飞行参数（高度、速度、喷幅）
- 飘移风险等级
- 病虫害类别与严重度

#### 3.4 第三阶段 —— "打"：变量精准执行

无人机（或多机编队）加载处方图，按图执行变量喷施。

**变量喷施执行链路**（完全复用青航原有硬件）：

```
处方图像素数据 → STM32单片机 → PWM信号 → 离心喷头转速调节 → 雾滴粒径+喷量变化
         ↑                                                    ↓
    RTK定位匹配                                        风速传感器反馈
    (位置与处方图对齐)                            BP-PINN在线推理调节
```

喷洒流量公式：

$$Q(x,y) = Q_{base} \times f(VI(x,y)) \times \frac{v_{real}}{v_{ref}}$$

其中 $Q(x,y)$ 为位置 $(x,y)$ 处的实际喷洒量，$Q_{base}$ 为基础喷洒量，$f(VI(x,y))$ 为基于植被指数的处方函数，$v_{real}/v_{ref}$ 为实际飞行速度与参考速度的比值修正。

**执行阶段的关键创新 —— 预响应触发补偿**：

原论文已验证：端到端延迟（感知→决策→执行）约为200-400ms，在飞行速度5m/s下对应1-2m的空间偏移。在大田场景中，处方图内不同区域（如"健康区→病害区"、"V3级→V1级"）的边界过渡同样存在这一问题。预响应机制将延迟转化为**空间提前量**，在距离边界约1-2m处提前调整喷施参数，确保：

- 病害斑块前缘不欠喷（提前开启高剂量）
- 健康区不误喷（提前切换低剂量/关闭）
- 长势等级边界过渡平滑（避免突变导致的沉积不均）

**多机协同**：针对千亩级地块，3-5架无人机编队作业，云端任务分配实现"分田到机、接力覆盖"，单日作业能力3000-5000亩。

#### 3.5 第四阶段 —— "验"：效果评估与闭环迭代

这是原系统所不具备的新环节，也是闭环完整性的关键。

**作业后验证方式**：
- **短期验证（作业后24-48h）**：利用水敏纸和采样点检测雾滴沉积密度、覆盖率和飘移量，对比处方图预期与实际沉积
- **中期验证（作业后7-14天）**：再次高光谱巡航，对比施药/施肥前后的植被指数变化（如DSI是否下降、NDVI是否回升、SPAD是否改善）
- **长期验证（收获期）**：对比变量作业区与对照区的产量差异，评估整体效益

**闭环迭代**：
- 沉积效果偏差 → 修正BP-PINN飘移模型参数
- 病虫害防治效果不足 → 更新病害阈值和剂量映射
- 长势改善不达预期 → 调整V1-V5分级的喷施量映射函数
- 产量数据 → 校准产量预测模型（随机森林权重更新）

### 四、技术迁移与适应性改造：六大关键改造

#### 4.1 场景差异分析

| 维度 | 南方柑橘园（原场景） | 东北大田作物（迁移场景） |
|------|---------------------|------------------------|
| **种植模式** | 离散/半连续，株行距大（3-5m），存在缺株间隙 | 连续密植覆盖，行距小（水稻20-30cm，玉米60-65cm） |
| **受药对象** | 单株树冠，三维立体目标 | 连续冠层面，二维平面目标 |
| **作业面积** | 单园几十亩至数百亩 | 单地块数千亩至上万亩 |
| **地形条件** | 丘陵起伏，高差变化大 | 平原开阔，地势平坦 |
| **病虫害特征** | 病虫害种类相对集中（柑橘黄龙病、红蜘蛛等） | 病虫害种类多样（稻瘟病、大豆蚜虫、玉米螟等） |
| **核心需求** | 对靶精准喷施（"点对点"） | 变量均匀覆盖（"面扫描"） |

#### 4.2 六大适应性改造

**（1）喷洒系统：从"对靶点射"到"变量面喷"**

原系统脉冲式电磁阀单株对靶 → 改造为PWM变量喷洒系统，通过实时调节占空比（0-100%）实现每平方米级别的变量施药/施肥。**STM32+离心喷头硬件链路完全复用。**

**（2）感知系统：从"RGB双目"到"高光谱+视觉+风场"多模态融合**

| 原系统（果园） | 新系统（大田） | 融合方式 |
|---------------|---------------|---------|
| 双目RGB相机 | 双目RGB + **128波段高光谱成像仪** + 多光谱相机 | 双目提供冠层结构，高光谱提供生化参数，多模态融合生成综合处方图 |
| — | 风速/风向传感器 | 实时风场数据输入BP-PINN飘移模型 |

**（3）飞行控制：从"仿地飞行"到"定高巡航+参数自适应"**

原丘陵果园需仿地飞行。大田地势平坦，优化为等高等速巡航模式（飞行高度1.5-3m），配合RTK-GNSS定位（精度±2cm），确保喷洒均匀性CV < 10%。**新增飞行参数自适应优化**——根据风场-冠层时序模型预测结果，针对不同作物自动调节飞行高度、速度和喷幅宽度。

**（4）路径规划：从"逐行扫描"到"全域网格覆盖"**

引入基于网格的全域覆盖路径规划算法：

$$\min \sum_{i=1}^{n} L_i + \lambda \cdot N_{turn}$$

其中 $L_i$ 为第 $i$ 段航迹长度，$N_{turn}$ 为转弯次数，$\lambda$ 为转弯惩罚系数。

**（5）决策系统：从"实时二值决策"到"处方图驱动+预响应补偿"**

原系统逐棵果树实时做喷/不喷二值决策 → 大田场景采用"先察后打"两阶段模式：高光谱离线生成处方图，无人机加载处方图在线执行。**处方图中的"非喷施区"等同于果园中的"空隙段"**，预响应机制确保边界过渡段的精准控制。

**（6）作业模式：从"单机闭环"到"察打分离+集群协同"**

将"察"和"打"解耦为两个阶段，适配大田千亩级作业需求：
- **察阶段**：专机巡航采集高光谱数据（轻量化、长续航）
- **打阶段**：多机编队加载处方图执行（3-5架协同）
- **优势**：将高光谱分析的计算压力从实时在线转移到离线处理，解决大面积作业的算力和续航瓶颈

### 七、应用场景与效益分析

#### 7.1 典型应用场景

**场景一：水稻稻瘟病精准防控（7-8月）**
- "察"：高光谱巡航发现叶瘟初发病区域（红边蓝移 > 10nm，隐性胁迫阶段）
- "析"：自动生成处方图，标定发病区域位置和严重度等级
- "打"：无人机加载处方图，对发病区域精准施药（三环唑/稻瘟灵），未发病区预防性低剂量喷施。预响应触发确保边界过渡精准
- "验"：7天后复飞高光谱对比DSI变化，评估防治效果
- **效果**：农药用量减少45%，防治效果持平或更优

**场景二：大豆花期变量追肥（6-7月）**
- "察"：高光谱监测大豆LAI空间分布，识别缺素（氮素不足）区域
- "析"：生成长势分级处方图（V1弱苗增施，V5旺长控施）
- "打"：变量追施叶面肥，不同等级区执行不同喷量
- "验"：14天后对比NDVI变化，评估追肥效果
- **效果**：大豆产量提升5%-8%，氮肥用量减少15%

**场景三：玉米灌浆期产量预估+倒伏预警（8-9月）**
- "察"：多时相高光谱数据融合（拔节期NDVI+灌浆期GNDVI）
- "析"：随机森林模型预测玉米单产；风场-冠层模型评估倒伏风险
- "验"：收获期实际产量与预测对比，校准模型
- **效果**：产量预测精度 > 90%，提前2个月为粮食收储提供决策依据

### 九、项目总结：从果园到粮仓的技术长征

本项目实现了四大跨越：

1. **场景跨越**：从南方丘陵柑橘园到东北平原大田作物，证明了察打一体技术路线的跨场景适应性
2. **感知跨越**：从RGB双目感知到128波段高光谱感知，从"看得到"到"看得透"，从定性判断到定量反演
3. **决策跨越**：从单株实时二值决策到"察-析-打-验"四环节闭环，处方图驱动+预响应补偿+多机协同+效果反馈
4. **价值跨越**：从服务经济作物（柑橘）到服务国家粮食安全（水稻、大豆、玉米），技术价值与国家战略深度契合

**一句话总结**：青航团队将已在南方柑橘园验证的"察打一体"精准植保技术体系——包括BP-PINN飘移控制、深度学习冠层感知、PWM变量喷施、预响应触发补偿等核心技术——创新迁移至东北大田粮食作物场景。通过引入**高光谱全域感知**作为驱动闭环的核心数据源，构建了**"察-析-打-验"四环节闭环**，实现了从"看树喷树"到"看谱施药"的技术范式升级，以"同一套技术底座、两种农业场景"的跨域创新，为黑龙江当好国家粮食安全"压舱石"提供了智能化装备支撑。
